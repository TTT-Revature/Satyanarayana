## 8. enumerate(), zip(), any(), and all()

These built-in functions help write cleaner and more Pythonic code.

### 8.1 enumerate()

`enumerate()` lets us loop through an iterable while obtaining both the index and corresponding value.

Without `enumerate()`:

```python
students = ["Ram", "Sam", "John"]

for i in range(len(students)):
    print(i, students[i])
```

Using `enumerate()`:

```python
students = ["Ram", "Sam", "John"]

for index, student in enumerate(students):
    print(index, student)
```

Output:

```text
0 Ram
1 Sam
2 John
```

Syntax:

```python
enumerate(iterable, start=0)
```

The optional `start` parameter specifies the starting index.

```python
students = ["Ram", "Sam", "John"]

for index, student in enumerate(students, start=1):
    print(index, student)
```

Output:

```text
1 Ram
2 Sam
3 John
```

**Real-world example: Displaying social media posts**

```python
posts = [
    "Python Tutorial",
    "Travel Photography",
    "Food Recipe"
]

for position, post in enumerate(posts, start=1):
    print(f"{position}. {post}")
```

### 8.2 zip()

`zip()` combines multiple iterables element by element.

```python
names = ["Ram", "Sam", "John"]
marks = [85, 90, 78]

result = zip(names, marks)

print(list(result))
```

Output:

```text
[('Ram', 85), ('Sam', 90), ('John', 78)]
```

Syntax:

```python
zip(iterable1, iterable2, ...)
```

Using a loop:

```python
names = ["Ram", "Sam", "John"]
marks = [85, 90, 78]

for name, mark in zip(names, marks):
    print(name, mark)
```

Output:

```text
Ram 85
Sam 90
John 78
```

By default, `zip()` stops when the shortest iterable is exhausted.

```python
names = ["Ram", "Sam", "John"]
marks = [85, 90]

print(list(zip(names, marks)))
```

Output:

```text
[('Ram', 85), ('Sam', 90)]
```

To detect unequal lengths, use `zip(..., strict=True)` in Python 3.10 and later:

```python
names = ["Ram", "Sam", "John"]
marks = [85, 90]

list(zip(names, marks, strict=True))
```

This raises `ValueError`.

**Real-world example: Product names and prices**

```python
products = ["Mobile", "Laptop", "Tablet"]
prices = [20000, 60000, 30000]

for product, price in zip(products, prices):
    print(f"{product}: Rs. {price}")
```

### 8.3 any()

`any()` returns `True` if at least one element in an iterable evaluates to `True`.

Syntax:

```python
any(iterable)
```

Example:

```python
marks = [35, 42, 28, 50]

result = any(mark >= 40 for mark in marks)

print(result)
```

Output:

```text
True
```

At least one student scored 40 or more.

Another example:

```python
values = [False, False, True]

print(any(values))  # True
```

If all elements are false or the iterable is empty, `any()` returns `False`.

**Real-world example: Checking product availability**

```python
stock = [0, 0, 10, 0]

if any(quantity > 0 for quantity in stock):
    print("Product available")
else:
    print("Out of stock")
```

### 8.4 all()

`all()` returns `True` only when every element in an iterable evaluates to `True`.

Syntax:

```python
all(iterable)
```

Example:

```python
marks = [75, 80, 90, 85]

result = all(mark >= 35 for mark in marks)

print(result)
```

Output:

```text
True
```

All students passed.

Another example:

```python
values = [True, True, True]

print(all(values))  # True
```

If any element is false, `all()` returns `False`.

**Real-world example: Checking required registration details**

```python
user = {
    "name": "Satya",
    "email": "satya@example.com",
    "phone": "9876543210"
}

required_fields = ["name", "email", "phone"]

if all(user.get(field) for field in required_fields):
    print("Registration details complete")
else:
    print("Missing registration details")
```

### 8.5 Difference between any() and all()

| Feature | `any()` | `all()` |
|---|---|---|
| Returns `True` when | At least one element is true | Every element is true |
| Returns `False` when | All elements are false | At least one element is false |
| Empty iterable | `False` | `True` |

```python
values = [True, False, True]

print(any(values))  # True
print(all(values))  # False
```

Both functions use short-circuit evaluation:

- `any()` stops after finding a true value.
- `all()` stops after finding a false value.
