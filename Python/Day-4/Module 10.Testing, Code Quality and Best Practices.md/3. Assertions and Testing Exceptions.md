## 3. Assertions and Testing Exceptions

### 3.1 What are assertions?

Assertions are statements that check whether a condition is true. Python provides the `assert` keyword.

Syntax:

```python
assert condition, "Optional error message"
```

If the condition is true, execution continues. If it is false, Python raises `AssertionError`.

```python
age = 20

assert age >= 18, "User must be an adult"

print("Registration successful")
```

If `age` is 15, the assertion fails:

```python
age = 15
assert age >= 18, "User must be an adult"
```

This raises `AssertionError`.

### 3.2 Assertions in unittest

```python
import unittest


def is_adult(age):
    return age >= 18


class TestUser(unittest.TestCase):

    def test_adult(self):
        self.assertTrue(is_adult(25))

    def test_minor(self):
        self.assertFalse(is_adult(15))


if __name__ == "__main__":
    unittest.main()
```

### 3.3 Testing exceptions using assertRaises()

A function may be expected to raise an exception for invalid input. For example, dividing by zero raises `ZeroDivisionError`.

```python
import unittest


def divide(a, b):
    return a / b


class TestDivision(unittest.TestCase):

    def test_division(self):
        self.assertEqual(divide(10, 2), 5)

    def test_division_by_zero(self):
        with self.assertRaises(ZeroDivisionError):
            divide(10, 0)


if __name__ == "__main__":
    unittest.main()
```

The test passes if the expected exception is raised. If no exception occurs, the test fails.

### 3.4 Testing custom exceptions

Consider a bank account application:

```python
class InsufficientBalanceError(Exception):
    pass


def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientBalanceError(
            "Insufficient account balance"
        )

    return balance - amount
```

Test the exception:

```python
import unittest

from bank import withdraw, InsufficientBalanceError


class TestBank(unittest.TestCase):

    def test_withdraw(self):
        self.assertEqual(withdraw(1000, 300), 700)

    def test_insufficient_balance(self):
        with self.assertRaises(InsufficientBalanceError):
            withdraw(500, 1000)


if __name__ == "__main__":
    unittest.main()
```

### 3.5 Testing exception messages

Use `assertRaisesRegex()` to verify an exception message:

```python
with self.assertRaisesRegex(ValueError, "Invalid age"):
    raise ValueError("Invalid age supplied")
```

### 3.6 `assert` vs testing-framework assertions

| Python `assert` | unittest assertion |
|---|---|
| Language keyword | Testing framework method |
| Useful for internal conditions and debugging | Used to verify expected test results |
| Example: `assert x > 0` | Example: `self.assertGreater(x, 0)` |
| Can be disabled with Python optimization (`-O`) | Framework assertions remain part of test execution |

**Best practice:** Do not use ordinary `assert` statements to validate user input or enforce critical business rules. Use explicit conditions and raise appropriate exceptions.
