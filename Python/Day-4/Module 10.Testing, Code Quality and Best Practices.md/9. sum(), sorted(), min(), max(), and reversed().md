## 9. sum(), sorted(), min(), max(), and reversed()

These built-in functions make common operations easier.

### 9.1 sum()

`sum()` calculates the total of elements in an iterable.

Syntax:

```python
sum(iterable, start=0)
```

Example:

```python
marks = [80, 90, 75, 85]

total = sum(marks)

print(total)  # 330
```

Using the optional starting value:

```python
numbers = [10, 20, 30]

print(sum(numbers, 100))  # 160
```

**Real-world example: Calculating cart total**

```python
cart_prices = [500, 1000, 250, 750]

total_amount = sum(cart_prices)

print("Cart Total:", total_amount)
```

### 9.2 sorted()

`sorted()` returns a new sorted list from an iterable.

Syntax:

```python
sorted(iterable, key=None, reverse=False)
```

Example:

```python
numbers = [5, 2, 8, 1, 3]

result = sorted(numbers)

print(result)  # [1, 2, 3, 5, 8]
```

Descending order:

```python
numbers = [5, 2, 8, 1, 3]

result = sorted(numbers, reverse=True)

print(result)  # [8, 5, 3, 2, 1]
```

Sorting strings:

```python
names = ["John", "Alice", "Sam", "David"]

print(sorted(names))
# ['Alice', 'David', 'John', 'Sam']
```

Sorting dictionaries by a key:

```python
products = [
    {"name": "Mobile", "price": 20000},
    {"name": "Laptop", "price": 60000},
    {"name": "Tablet", "price": 30000}
]

sorted_products = sorted(
    products,
    key=lambda product: product["price"]
)

print(sorted_products)
```

The result is ordered from the least expensive product to the most expensive product.

### 9.3 sorted() vs sort()

| `sorted()` | `list.sort()` |
|---|---|
| Works with any iterable | Works only with lists |
| Returns a new list | Modifies the original list |
| Original data remains unchanged | Original list is changed |
| Example: `sorted(numbers)` | Example: `numbers.sort()` |

Example:

```python
numbers = [4, 2, 5, 1]

new_numbers = sorted(numbers)

print(numbers)      # [4, 2, 5, 1]
print(new_numbers)  # [1, 2, 4, 5]
```

### 9.4 min()

`min()` returns the smallest element.

```python
numbers = [10, 5, 20, 2, 15]

print(min(numbers))  # 2
```

It also supports multiple arguments:

```python
print(min(10, 20, 5, 30))  # 5
```

Using a key:

```python
students = [
    {"name": "Ram", "marks": 85},
    {"name": "Sam", "marks": 65},
    {"name": "John", "marks": 90}
]

lowest = min(
    students,
    key=lambda student: student["marks"]
)

print(lowest)
# {'name': 'Sam', 'marks': 65}
```

### 9.5 max()

`max()` returns the largest element.

```python
numbers = [10, 5, 20, 2, 15]

print(max(numbers))  # 20
```

Using a key:

```python
students = [
    {"name": "Ram", "marks": 85},
    {"name": "Sam", "marks": 65},
    {"name": "John", "marks": 90}
]

top_student = max(
    students,
    key=lambda student: student["marks"]
)

print(top_student)
# {'name': 'John', 'marks': 90}
```

### 9.6 reversed()

`reversed()` returns an iterator that produces elements in reverse order.

Syntax:

```python
reversed(sequence)
```

Example:

```python
numbers = [10, 20, 30, 40]

result = reversed(numbers)

print(list(result))  # [40, 30, 20, 10]
```

Using a loop:

```python
names = ["Ram", "Sam", "John"]

for name in reversed(names):
    print(name)
```

Output:

```text
John
Sam
Ram
```

`reversed()` does not modify the original list.

### 9.7 Quick comparison

| Function | Purpose | Returns |
|---|---|---|
| `sum()` | Calculates total | Number |
| `sorted()` | Returns sorted elements | New list |
| `min()` | Finds smallest element | Element |
| `max()` | Finds largest element | Element |
| `reversed()` | Iterates in reverse order | Iterator |
