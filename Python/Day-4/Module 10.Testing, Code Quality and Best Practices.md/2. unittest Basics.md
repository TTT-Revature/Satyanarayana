## 2. unittest Basics

### 2.1 What is unittest?

`unittest` is Python's built-in testing framework. It allows developers to create and execute automated tests without installing an external testing library.

It provides:

- Test cases
- Test methods
- Assertions
- Test fixtures
- Test suites
- Test runners

### 2.2 Basic structure of unittest

A test class generally inherits from `unittest.TestCase`.

```python
import unittest


class TestExample(unittest.TestCase):

    def test_something(self):
        self.assertEqual(10, 10)


if __name__ == "__main__":
    unittest.main()
```

| Component | Description |
|---|---|
| `unittest` | Python testing module |
| `TestCase` | Base class for test cases |
| `test_` | Prefix used for automatically discovered test methods |
| `assertEqual()` | Checks whether two values are equal |
| `unittest.main()` | Runs the tests |

### 2.3 Practical example: E-commerce application

Create `shopping.py`:

```python
def calculate_total(price, quantity):
    return price * quantity


def apply_discount(total, discount):
    return total - (total * discount / 100)


def calculate_delivery_charge(total):
    if total >= 1000:
        return 0
    return 50
```

Create `test_shopping.py`:

```python
import unittest

from shopping import (
    calculate_total,
    apply_discount,
    calculate_delivery_charge
)


class TestShopping(unittest.TestCase):

    def test_calculate_total(self):
        result = calculate_total(100, 3)
        self.assertEqual(result, 300)

    def test_apply_discount(self):
        result = apply_discount(1000, 10)
        self.assertEqual(result, 900)

    def test_delivery_free(self):
        result = calculate_delivery_charge(1500)
        self.assertEqual(result, 0)

    def test_delivery_charge(self):
        result = calculate_delivery_charge(500)
        self.assertEqual(result, 50)


if __name__ == "__main__":
    unittest.main()
```

Run the tests:

```bash
python -m unittest test_shopping.py -v
```

Illustrative output:

```text
test_apply_discount ... ok
test_calculate_total ... ok
test_delivery_charge ... ok
test_delivery_free ... ok

Ran 4 tests

OK
```

### 2.4 Important unittest assertions

Assertions are methods used to verify whether an expected condition is true.

| Assertion | Purpose | Example |
|---|---|---|
| `assertEqual(a, b)` | Checks equality | `self.assertEqual(10, 10)` |
| `assertNotEqual(a, b)` | Checks inequality | `self.assertNotEqual(10, 20)` |
| `assertTrue(x)` | Checks whether a condition is true | `self.assertTrue(5 > 2)` |
| `assertFalse(x)` | Checks whether a condition is false | `self.assertFalse(5 < 2)` |
| `assertIs(a, b)` | Checks object identity | `self.assertIs(result, None)` |
| `assertIsNone(x)` | Checks whether value is `None` | `self.assertIsNone(result)` |
| `assertIsNotNone(x)` | Checks value is not `None` | `self.assertIsNotNone(result)` |
| `assertIn(a, b)` | Checks membership | `self.assertIn("Python", languages)` |
| `assertNotIn(a, b)` | Checks absence | `self.assertNotIn("Java", languages)` |
| `assertGreater(a, b)` | Checks whether `a` is greater | `self.assertGreater(10, 5)` |
| `assertLess(a, b)` | Checks whether `a` is smaller | `self.assertLess(5, 10)` |

### 2.5 setUp() and tearDown()

When multiple test cases require the same initial data, use `setUp()` and `tearDown()`.

- `setUp()` runs before each test method.
- `tearDown()` runs after each test method, including when the test fails or raises an exception.

```python
import unittest


class TestShoppingCart(unittest.TestCase):

    def setUp(self):
        self.cart = {
            "price": 500,
            "quantity": 2
        }

    def test_total(self):
        total = self.cart["price"] * self.cart["quantity"]
        self.assertEqual(total, 1000)

    def test_quantity(self):
        self.assertEqual(self.cart["quantity"], 2)

    def tearDown(self):
        print("Test completed")


if __name__ == "__main__":
    unittest.main()
```

Execution flow for each test:

```text
setUp()
   |
   v
test method
   |
   v
tearDown()
```

Each test gets its own setup and teardown.
