## 5. pip and Package Installation

### 5.1 What is pip?

`pip` is Python's standard package installer. It installs, upgrades, and uninstalls third-party Python packages.

Examples:

| Package | Purpose |
|---|---|
| NumPy | Numerical computing |
| Pandas | Data manipulation |
| Django | Web development |
| Flask | Web development |
| Requests | HTTP requests |
| Matplotlib | Data visualization |
| Scikit-learn | Machine learning |
| TensorFlow | Deep learning |

### 5.2 Checking pip

```bash
python -m pip --version
```

### 5.3 Installing packages

Install one package:

```bash
python -m pip install requests
```

Install multiple packages:

```bash
python -m pip install numpy pandas matplotlib
```

### 5.4 Installing a specific version

```bash
python -m pip install numpy==1.26.4
```

Common version specifiers:

| Operator | Meaning | Example |
|---|---|---|
| `==` | Exact version | `numpy==1.26.4` |
| `>=` | Greater than or equal to | `numpy>=1.26` |
| `<=` | Less than or equal to | `numpy<=2.0` |
| `>` | Greater than | `numpy>1.20` |
| `<` | Less than | `numpy<2.0` |
| `!=` | Exclude a version | `numpy!=1.25.0` |
| `~=` | Compatible release | `requests~=2.31` |

### 5.5 Upgrading a package

```bash
python -m pip install --upgrade requests
```

This upgrades Requests subject to the applicable version requirements.

### 5.6 Uninstalling a package

```bash
python -m pip uninstall requests
```

Skip the confirmation prompt:

```bash
python -m pip uninstall -y requests
```

### 5.7 Listing installed packages

```bash
python -m pip list
```

Example:

```text
Package       Version
------------- -------
numpy         2.2.0
pandas        2.2.3
requests      2.32.3
```

### 5.8 Displaying package information

```bash
python -m pip show requests
```

This displays package metadata, version, installation location, and dependency information.

### 5.9 Finding packages

Modern pip does not provide the old `pip search` functionality. Search for packages through the Python Package Index (PyPI): https://pypi.org/.

### 5.10 What is PyPI?

The **Python Package Index (PyPI)** is the main public repository where Python developers publish and distribute packages. pip generally obtains packages from PyPI unless configured to use another package index or source.

### 5.11 Why use `python -m pip`?

A computer may have multiple Python installations. A standalone `pip` command might belong to a different interpreter than the one used to run the application.

Using:

```bash
python -m pip install requests
```

runs pip through the selected Python interpreter and helps keep installation aligned with that interpreter.

**Best practice:** Prefer `python -m pip` for consistent package installation.
