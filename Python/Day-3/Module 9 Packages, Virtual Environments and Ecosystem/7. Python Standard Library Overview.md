## 7. Python Standard Library Overview

### 7.1 What is the standard library?

The Python standard library is a collection of modules and packages distributed with Python. These modules provide functionality for mathematics, files, dates, operating systems, networking, serialization, databases, logging, and more.

### 7.2 Important standard library modules

#### A. `math`

Used for mathematical operations.

```python
import math

print(math.sqrt(25))
print(math.factorial(5))
print(math.pi)
print(math.ceil(4.2))
print(math.floor(4.8))
```

Output:

```text
5.0
120
3.141592653589793
5
4
```

| Function | Purpose |
|---|---|
| `sqrt()` | Square root |
| `pow()` | Power calculation |
| `factorial()` | Factorial |
| `ceil()` | Round upward |
| `floor()` | Round downward |
| `fabs()` | Absolute floating-point value |

#### B. `random`

Used to generate pseudo-random values.

```python
import random

print(random.randint(1, 10))
print(random.choice(["Python", "Java", "C++"]))

numbers = [10, 20, 30, 40]
random.shuffle(numbers)
print(numbers)
```

Uses include games, simulations, sampling, and test data. Do not use `random` for security-sensitive tokens or passwords; use `secrets` instead.

#### C. `datetime`

Used for dates and times.

```python
from datetime import datetime, date

current_date = date.today()
current_time = datetime.now()

print("Date:", current_date)
print("Date and Time:", current_time)
```

Create a specific date:

```python
from datetime import date

event_date = date(2026, 12, 25)
print(event_date)
```

Uses include order dates, login timestamps, appointments, and delivery-date calculations.

#### D. `os`

Used to interact with the operating system.

```python
import os

print(os.getcwd())
print(os.listdir())
os.mkdir("new_folder")
```

| Function or attribute | Purpose |
|---|---|
| `getcwd()` | Current working directory |
| `listdir()` | List directory contents |
| `mkdir()` | Create a directory |
| `remove()` | Remove a file |
| `rename()` | Rename a file |
| `environ` | Access environment variables |

#### E. `sys`

Provides access to Python interpreter and runtime information.

```python
import sys

print(sys.version)
print(sys.executable)
print(sys.platform)
print(sys.path)
```

Uses include checking Python versions, accessing command-line arguments, inspecting import paths, and examining interpreter configuration.

#### F. `pathlib`

Provides object-oriented filesystem path handling.

```python
from pathlib import Path

project_path = Path("ecommerce")

print(project_path.exists())
print(project_path.name)
print(project_path.resolve())
```

Create a directory:

```python
from pathlib import Path

folder = Path("uploads")
folder.mkdir(exist_ok=True)
```

Read a file:

```python
from pathlib import Path

file_path = Path("message.txt")
content = file_path.read_text(encoding="utf-8")
print(content)
```

`pathlib` is generally preferable to manually concatenating filesystem paths.

#### G. `json`

Used for JSON serialization and deserialization.

```python
import json

user = {
    "name": "Rahul",
    "age": 25,
    "city": "Hyderabad"
}

json_data = json.dumps(user)
print(json_data)
```

Convert a JSON string back into a Python object:

```python
data = json.loads(json_data)
print(data["name"])
```

Uses include API communication, configuration files, and structured data exchange.

#### H. `csv`

Used to read and write CSV files.

Write a CSV:

```python
import csv

with open("users.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["ID", "Name", "Age"])
    writer.writerow([1, "Rahul", 25])
    writer.writerow([2, "Priya", 23])
```

Read a CSV:

```python
import csv

with open("users.csv", "r", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

#### I. `re`

Used for regular expressions and pattern matching.

```python
import re

email = "rahul@gmail.com"
pattern = r"^[\w.-]+@[\w.-]+\.\w+$"

if re.match(pattern, email):
    print("Valid email format")
else:
    print("Invalid email format")
```

Common functions include `match()`, `search()`, `findall()`, `sub()`, and `split()`.

#### J. `collections`

Provides specialized container data types.

Example using `Counter`:

```python
from collections import Counter

items = ["apple", "banana", "apple", "orange", "banana", "apple"]
result = Counter(items)

print(result)
```

Output:

```text
Counter({'apple': 3, 'banana': 2, 'orange': 1})
```

| Class | Purpose |
|---|---|
| `Counter` | Counts occurrences |
| `defaultdict` | Dictionary with default values |
| `deque` | Efficient double-ended queue |
| `namedtuple` | Tuple with named fields |

#### K. `sqlite3`

Used to interact with SQLite databases.

```python
import sqlite3

connection = sqlite3.connect("ecommerce.db")
cursor = connection.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY,
    name TEXT
)
""")

cursor.execute(
    "INSERT INTO users (name) VALUES (?)",
    ("Rahul",)
)

connection.commit()
connection.close()
```

SQLite is useful for lightweight database applications and prototypes. Parameterized SQL helps avoid SQL injection when inserting values.

#### L. `logging`

Used to record application events and errors.

```python
import logging

logging.basicConfig(level=logging.INFO)

logging.debug("Debug message")
logging.info("Application started")
logging.warning("Low inventory")
logging.error("Payment failed")
logging.critical("Database unavailable")
```

| Level | Purpose |
|---|---|
| DEBUG | Detailed debugging information |
| INFO | Normal application events |
| WARNING | Potential problems |
| ERROR | An operation failed |
| CRITICAL | Serious application failure |

#### M. `secrets`

Used to generate cryptographically secure random values.

```python
import secrets

token = secrets.token_hex(16)
print(token)
```

Useful for secure tokens and password-reset tokens.

#### N. `argparse`

Used to create command-line applications.

```python
import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--name", required=True)
args = parser.parse_args()

print("Hello", args.name)
```

Execute:

```bash
python main.py --name Rahul
```

Output:

```text
Hello Rahul
```
