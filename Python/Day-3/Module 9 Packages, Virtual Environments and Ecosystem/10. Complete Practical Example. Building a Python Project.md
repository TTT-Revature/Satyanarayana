## 10. Complete Practical Example: Building a Python Project

This example combines packages, modules, `__init__.py`, imports, virtual environments, pip, dependencies, and project structure.

### Step 1: Create the project directory

```bash
mkdir ecommerce
cd ecommerce
```

### Step 2: Create a virtual environment

```bash
python -m venv .venv
```

Activate on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### Step 3: Install dependencies

For this example, install Flask:

```bash
python -m pip install flask
```

### Step 4: Create the project structure

```text
ecommerce/
├── src/
│   └── ecommerce/
│       ├── __init__.py
│       ├── main.py
│       ├── users/
│       │   ├── __init__.py
│       │   └── authentication.py
│       └── products/
│           ├── __init__.py
│           └── catalog.py
├── .venv/
├── tests/
├── .gitignore
├── requirements.txt
├── README.md
└── pyproject.toml
```

### Step 5: Write the user module

**src/ecommerce/users/authentication.py**

```python
def register_user(name, email):
    return {
        "name": name,
        "email": email,
        "status": "Registered"
    }

def login_user(email):
    return f"Welcome back, {email}"
```

### Step 6: Write the product module

**src/ecommerce/products/catalog.py**

```python
products = [
    {"id": 101, "name": "Laptop", "price": 55000},
    {"id": 102, "name": "Mobile", "price": 25000},
    {"id": 103, "name": "Headphones", "price": 2000}
]

def get_products():
    return products

def get_product_by_id(product_id):
    for product in products:
        if product["id"] == product_id:
            return product
    return None
```

### Step 7: Configure package exports

**src/ecommerce/users/__init__.py**
```python
from .authentication import register_user, login_user
```

**src/ecommerce/products/__init__.py**
```python
from .catalog import get_products, get_product_by_id
```

### Step 8: Create the application entry point

**src/ecommerce/main.py**

```python
from ecommerce.users import register_user, login_user
from ecommerce.products import get_products, get_product_by_id

def main():
    # Register a user
    user = register_user("Rahul", "rahul@gmail.com")
    print("User Details:", user)

    # Login
    print(login_user("rahul@gmail.com"))

    # Display products
    print("\nAvailable Products:")
    for product in get_products():
        print(product)

    # Search product
    product = get_product_by_id(101)
    print("\nSelected Product:", product)

if __name__ == "__main__":
    main()
```

### Step 9: Create `pyproject.toml`

```toml
[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"

[project]
name = "ecommerce"
version = "1.0.0"
description = "A simple Python e-commerce application"
requires-python = ">=3.10"
dependencies = [
    "flask"
]

[tool.setuptools.packages.find]
where = ["src"]
```

### Step 10: Install the project in editable mode

From the project root:

```bash
python -m pip install -e .
```

Editable installation lets Python import the source package without copying it into the environment's `site-packages` directory.

### Step 11: Generate `requirements.txt`

```bash
python -m pip freeze > requirements.txt
```

### Step 12: Run the application

```bash
python -m ecommerce.main
```

Expected output:

```text
User Details: {'name': 'Rahul', 'email': 'rahul@gmail.com', 'status': 'Registered'}

Welcome back, rahul@gmail.com

Available Products:
{'id': 101, 'name': 'Laptop', 'price': 55000}
{'id': 102, 'name': 'Mobile', 'price': 25000}
{'id': 103, 'name': 'Headphones', 'price': 2000}

Selected Product: {'id': 101, 'name': 'Laptop', 'price': 55000}
```

This project demonstrates how the different concepts work together in a small application.

## 11. Important Interview Questions and Answers

### 1. What is the difference between a module and a package?

A module is a single Python file containing reusable code, whereas a package organizes related modules into a directory structure.

### 2. What is the purpose of `__init__.py`?

It marks a regular package and can initialize the package or expose selected functions and classes.

### 3. Is `__init__.py` mandatory?

No. Python supports namespace packages without `__init__.py` from Python 3.3 onward.

### 4. What is the difference between absolute and relative imports?

Absolute imports specify the complete package path, whereas relative imports specify a module's location relative to the current package.

### 5. What is a virtual environment?

A virtual environment is an isolated Python environment that lets projects maintain separate dependencies and package versions.

### 6. What is `venv`?

`venv` is a Python standard library module used to create virtual environments.

### 7. What is pip?

pip is Python's package installer, used to install, upgrade, and uninstall third-party packages.

### 8. What is PyPI?

PyPI is the Python Package Index, an online repository for distributing Python packages.

### 9. What is the purpose of `requirements.txt`?

It specifies the Python packages and version requirements needed by a project.

### 10. What does `pip freeze` do?

It displays installed distributions and their versions in the current environment.

### 11. What is the difference between direct and transitive dependencies?

Direct dependencies are packages explicitly used by an application. Transitive dependencies are packages required by those direct dependencies.

### 12. Why should `.venv` be added to `.gitignore`?

It prevents large, environment-specific package installations from being committed to the repository.

### 13. Why should `.env` be ignored?

It often contains sensitive information such as passwords, API keys, and database credentials.

### 14. What is the difference between a standard library and a third-party library?

The standard library comes with Python, while third-party libraries are separately installed, commonly through pip.

### 15. Why is project structure important?

It improves maintainability, readability, scalability, collaboration, and testing.
