## 3. Absolute and Relative Imports

Imports allow one Python module to access functionality defined in another module.

### 3.1 Absolute imports

An absolute import specifies the package path from the import root.

```text
social_media/
├── main.py
├── users/
│   ├── __init__.py
│   └── authentication.py
└── posts/
    ├── __init__.py
    └── create_post.py
```

**users/authentication.py**
```python
def login_user():
    print("User logged in")
```

**posts/create_post.py**
```python
from users.authentication import login_user

def create_post():
    login_user()
    print("Post created")
```

`from users.authentication import login_user` is an absolute import. It starts from the import root rather than the current module's package.

Advantages:
- Dependencies are explicit.
- Imports are easy to understand.
- They work well across large projects.
- They reduce ambiguity.

### 3.2 Relative imports

Relative imports specify a module's location relative to the current package. They use dots.

| Syntax | Meaning |
|---|---|
| `.` | Current package |
| `..` | Parent package |
| `...` | Grandparent package |

Example:

```text
social_media/
├── main.py
└── users/
    ├── __init__.py
    ├── authentication.py
    └── profile/
        ├── __init__.py
        └── user_profile.py
```

**users/authentication.py**
```python
def get_user():
    return "Rahul"
```

**users/profile/user_profile.py**
```python
from ..authentication import get_user

def display_profile():
    name = get_user()
    print("User:", name)
```

The two dots move from `users.profile` to its parent package, `users`, and import `authentication`.

### 3.3 Absolute vs relative imports

| Feature | Absolute import | Relative import |
|---|---|---|
| Reference | Complete package path | Current package location |
| Example | `from users.auth import login` | `from .auth import login` |
| Readability | Explicit | Compact |
| Context | Clear from import path | Depends on package location |
| Common usage | Across packages | Within a package |

### 3.4 Relative imports and direct execution

Executing a package file directly can cause relative imports to fail:

```bash
python users/profile/user_profile.py
```

A relative import in that file may produce:

```text
ImportError: attempted relative import with no known parent package
```

Python is treating the file as a standalone script rather than as part of its package.

When the package is importable from the current working directory, run it as a module from the project root:

```bash
python -m users.profile.user_profile
```

**Guideline:** Absolute imports are useful for clearly showing dependencies across a project. Relative imports are useful for related modules within a package.
