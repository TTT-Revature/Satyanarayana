## 6. `requirements.txt` and Dependencies

### 6.1 What are dependencies?

A dependency is an external package or library that an application requires.

For example, a machine learning application might depend on:
- NumPy for numerical operations.
- Pandas for data processing.
- Scikit-learn for machine learning.
- Matplotlib for visualization.

### 6.2 What is `requirements.txt`?

`requirements.txt` is a text file commonly used to list the Python packages needed by a project.

Example:

```text
numpy==2.2.0
pandas==2.2.3
requests==2.32.3
matplotlib==3.10.0
scikit-learn==1.6.1
```

It helps other developers install the project's dependencies.

### 6.3 Creating `requirements.txt`

Activate the project's virtual environment, then run:

```bash
python -m pip freeze > requirements.txt
```

This writes installed distributions and versions to the file. It generally includes both directly installed packages and their transitive dependencies.

### 6.4 Installing dependencies from the file

Create and activate a virtual environment, then run:

```bash
python -m pip install -r requirements.txt
```

The `-r` option tells pip to read package requirements from the specified file.

### 6.5 Dependency version management

For example:

```text
requests==2.32.3
```

This pins Requests to an exact version. Version constraints help make installations more predictable and reduce unexpected changes, although a pinned requirements file alone does not guarantee identical environments across every operating system and Python version.

### 6.6 Direct and transitive dependencies

**Direct dependencies** are packages that your application explicitly uses.

```python
import requests
import pandas
```

Here, Requests and Pandas are direct dependencies.

**Transitive dependencies** are packages required by other dependencies. For example, Requests depends on packages such as `urllib3`, which your application may not import directly.

### 6.7 `requirements.txt` vs `pyproject.toml`

Modern Python projects commonly use `pyproject.toml` for project metadata, build configuration, and dependency declarations.

| Feature | requirements.txt | pyproject.toml |
|---|---|---|
| Main purpose | Installation requirements | Project and build configuration |
| Dependencies | Yes | Yes |
| Version constraints | Commonly pinned | Can specify constraints |
| Build configuration | No standard role | Yes |
| Project metadata | No standard role | Yes |

Example `pyproject.toml`:

```toml
[project]
name = "ecommerce-app"
version = "1.0.0"
description = "An e-commerce application"
requires-python = ">=3.10"

dependencies = [
    "requests>=2.31",
    "pandas>=2.2"
]
```

A project may use both files for different purposes.
