## 3. List Copying and Mutability

This is an important concept because it explains how Python handles objects in memory.

### 3.1 What is Mutability?
Mutability refers to whether an object can be modified after it is created.

Python data structures can be classified as:

| Mutable | Immutable |
| :--- | :--- |
| List | Tuple |
| Set | String |
| Dictionary | Integer |
| | Float |
| | Boolean |

Lists are mutable, which means we can modify their elements without creating a completely new list.

**Example:**
```python
numbers = [10, 20, 30]

numbers[1] = 200

print(numbers)
```

**Output:**
```text
[10, 200, 30]
```
The list is modified directly.

---

### 3.2 Understanding List References
Consider the following example:
```python
list1 = [10, 20, 30]

list2 = list1

list2.append(40)

print(list1)
print(list2)
```

**Output:**
```text
[10, 20, 30, 40]
[10, 20, 30, 40]
```

**Why does this happen?**
Because `list2 = list1` does not create a new list. Both `list1` and `list2` point to the exact same list object `[10, 20, 30, 40]` in memory.

---

### 3.3 Shallow Copy
A shallow copy creates a new outer list, but nested mutable objects are still shared.

There are three common ways to create a shallow copy:

**Method 1: Using `copy()`**
```python
list1 = [10, 20, 30]

list2 = list1.copy()

list2.append(40)

print(list1)
print(list2)
```

**Output:**
```text
[10, 20, 30]
[10, 20, 30, 40]
```

**Method 2: Using slicing**
```python
list1 = [10, 20, 30]

list2 = list1[:]

print(list2)
```

**Method 3: Using `list()`**
```python
list1 = [10, 20, 30]

list2 = list(list1)

print(list2)
```

---

### 3.4 Deep Copy
A deep copy creates a completely independent copy, including nested mutable objects. It is available through Python's `copy` module.

```python
import copy

list1 = [[10, 20], [30, 40]]

list2 = copy.deepcopy(list1)

list2[0][0] = 100

print(list1)
print(list2)
```

**Output:**
```text
[[10, 20], [30, 40]]
[[100, 20], [30, 40]]
```
The original nested list remains unchanged.

#### Shallow Copy vs Deep Copy

| Shallow Copy | Deep Copy |
| :--- | :--- |
| Copies the outer object | Copies the outer and nested objects |
| Nested objects are shared | Nested objects are independent |
| Faster in general | May require more time and memory |
| `copy.copy()` | `copy.deepcopy()` |

**When should we use them?**
* Use **assignment** when you intentionally want multiple references to the same list.
* Use **shallow copying** when you only need an independent outer list.
* Use **deep copying** when nested data must also remain independent.
