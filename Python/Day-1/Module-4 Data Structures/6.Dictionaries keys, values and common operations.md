## 6. Dictionaries: Keys, Values and Common Operations

### 6.1 What is a Dictionary?
A dictionary is a Python data structure used to store information in key-value pairs. Each key is associated with a corresponding value.

**Characteristics:**
* Stores data as key-value pairs.
* Mutable.
* Maintains insertion order in modern Python.
* Keys must be unique.
* Keys must be hashable.
* Values can be of any data type.

**Example:**
```python
student = {
    "name": "Rahul",
    "age": 21,
    "marks": 85
}

print(student)
```

**Output:**
```text
{'name': 'Rahul', 'age': 21, 'marks': 85}
```

| Key | Value |
| :--- | :--- |
| `name` | Rahul |
| `age` | 21 |
| `marks` | 85 |

---

### 6.2 Creating Dictionaries

**Method 1: Using curly braces**
```python
student = {
    "name": "Priya",
    "age": 22,
    "course": "M.Tech"
}
```

**Method 2: Creating an empty dictionary**
```python
student = {}

print(student)
```

**Method 3: Using `dict()`**
```python
student = dict(name="Rahul", age=21, marks=85)

print(student)
```

**Output:**
```text
{'name': 'Rahul', 'age': 21, 'marks': 85}
```

**Method 4: Using a list of tuples**
```python
student = dict([
    ("name", "Rahul"),
    ("age", 21),
    ("marks", 85)
])

print(student)
```

---

### 6.3 Accessing Dictionary Values
We can access values using their corresponding keys.
```python
student = {
    "name": "Rahul",
    "age": 21,
    "marks": 85
}

print(student["name"])
print(student["age"])
```

**Output:**
```text
Rahul
21
```

#### Using `get()`
The `get()` method safely accesses a value.
```python
student = {
    "name": "Rahul",
    "age": 21
}

print(student.get("name"))
print(student.get("marks"))
```

**Output:**
```text
Rahul
None
```

We can provide a default value:
```python
print(student.get("marks", 0))
```

**Output:**
```text
0
```

**Difference between square brackets and `get()`:**

| `student["marks"]` | `student.get("marks")` |
| :--- | :--- |
| Raises `KeyError` if key is missing | Returns `None` by default |
| Direct access | Safe access |
| Can use only existing keys | Can provide default values |

---

### 6.4 Adding and Updating Dictionary Elements
We can add a new key-value pair or update an existing value.
```python
student = {
    "name": "Rahul",
    "age": 21
}

student["marks"] = 90
student["age"] = 22

print(student)
```

**Output:**
```text
{'name': 'Rahul', 'age': 22, 'marks': 90}
```

#### Using `update()`
```python
student = {
    "name": "Rahul",
    "age": 21
}

student.update({
    "age": 22,
    "marks": 90
})

print(student)
```

**Output:**
```text
{'name': 'Rahul', 'age': 22, 'marks': 90}
```

---

### 6.5 Removing Dictionary Elements

#### `pop()`
Removes the specified key and returns its value.
```python
student = {
    "name": "Rahul",
    "age": 21,
    "marks": 85
}

result = student.pop("age")

print(result)
print(student)
```

**Output:**
```text
21
{'name': 'Rahul', 'marks': 85}
```

#### `popitem()`
Removes and returns the last inserted key-value pair.
```python
student = {
    "name": "Rahul",
    "age": 21,
    "marks": 85
}

print(student.popitem())
```

**Output:**
```text
('marks', 85)
```

#### `del`
Deletes a particular key-value pair.
```python
student = {
    "name": "Rahul",
    "age": 21
}

del student["age"]

print(student)
```

**Output:**
```text
{'name': 'Rahul'}
```

#### `clear()`
Removes all elements.
```python
student = {
    "name": "Rahul",
    "age": 21
}

student.clear()

print(student)
```

**Output:**
```text
{}
```

### 6.6 Dictionary Methods

| Method | Purpose |
| :--- | :--- |
| `keys()` | Returns all keys |
| `values()` | Returns all values |
| `items()` | Returns key-value pairs |
| `get()` | Safely accesses a value |
| `update()` | Adds or updates elements |
| `pop()` | Removes a specified key |
| `popitem()` | Removes the last inserted pair |
| `clear()` | Removes all elements |
| `copy()` | Creates a shallow copy |
| `setdefault()` | Returns a value or inserts a default |

#### `keys()`
```python
student = {
    "name": "Rahul",
    "age": 21,
    "marks": 85
}

print(student.keys())
```

**Output:**
```text
dict_keys(['name', 'age', 'marks'])
```

#### `values()`
```python
print(student.values())
```

**Output:**
```text
dict_values(['Rahul', 21, 85])
```

#### `items()`
```python
print(student.items())
```

**Output:**
```text
dict_items([('name', 'Rahul'), ('age', 21), ('marks', 85)])
```

#### Iterating through a dictionary

**Iterating through keys:**
```python
student = {
    "name": "Rahul",
    "age": 21,
    "marks": 85
}

for key in student:
    print(key)
```

**Output:**
```text
name
age
marks
```

**Iterating through values:**
```python
for value in student.values():
    print(value)
```

**Output:**
```text
Rahul
21
85
```

**Iterating through key-value pairs:**
```python
for key, value in student.items():
    print(key, ":", value)
```

**Output:**
```text
name : Rahul
age : 21
marks : 85
```

### 6.7 Dictionary Membership
The `in` operator checks whether a key exists in the dictionary.
```python
student = {
    "name": "Rahul",
    "age": 21
}

print("name" in student)
print("marks" in student)
```

**Output:**
```text
True
False
```
**Important:** By default, dictionary membership checks keys, not values.
