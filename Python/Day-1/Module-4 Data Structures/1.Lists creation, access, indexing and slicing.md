# Python Data Structures – In-Depth Explanation

Data structures are one of the most important concepts in Python programming. They allow us to store, organize, access, modify, and process data efficiently.

Python provides four major built-in collection data structures:
* **Lists** – Store multiple items in an ordered and mutable collection.
* **Tuples** – Store multiple items in an ordered but immutable collection.
* **Sets** – Store unique items in an unordered collection.
* **Dictionaries** – Store data in key-value pairs.

We will understand each concept step by step, with syntax, examples, outputs, practical applications, and important differences.

---

## 1. Lists: Creation, Access, Indexing and Slicing

### 1.1 What is a List?
A list is a built-in Python data structure used to store multiple values in a single variable.

Lists are:
* **Ordered:** Elements maintain their insertion order.
* **Mutable:** Elements can be modified after creation.
* **Allow duplicates:** The same value can appear multiple times.
* **Heterogeneous:** Different data types can be stored together.
* **Dynamic:** Their size can increase or decrease.

#### Example
```python
students = ["Rahul", "Priya", "Arjun", "Sneha"]

print(students)
```

**Output:**
```text
['Rahul', 'Priya', 'Arjun', 'Sneha']
```
Here, `students` is a list containing four string elements.

---

### 1.2 Creating Lists
There are different ways to create lists in Python.

**Method 1: Using square brackets**
```python
numbers = [10, 20, 30, 40, 50]

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40, 50]
```

**Method 2: Creating an empty list**
```python
list1 = []

print(list1)
```

**Output:**
```text
[]
```
An empty list can be populated later.

**Method 3: Using the `list()` constructor**
```python
numbers = list((10, 20, 30, 40))

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40]
```

**Method 4: Creating a list with different data types**
```python
student = ["Rahul", 21, 85.5, True]

print(student)
```

**Output:**
```text
['Rahul', 21, 85.5, True]
```

**Method 5: Creating a list with duplicate values**
```python
numbers = [10, 20, 10, 30, 20]

print(numbers)
```

**Output:**
```text
[10, 20, 10, 30, 20]
```
Duplicates are allowed in lists.

### 1.3 Accessing List Elements
We can access individual elements using their index positions. Python uses zero-based indexing, meaning the first element has index `0`.

**Example:**
```python
languages = ["Python", "Java", "C", "JavaScript"]

print(languages[0])
print(languages[1])
print(languages[2])
print(languages[3])
```

**Output:**
```text
Python
Java
C
JavaScript
```

| Element | Python | Java | C | JavaScript |
| :--- | :---: | :---: | :---: | :---: |
| **Positive Index** | 0 | 1 | 2 | 3 |
| **Negative Index** | -4 | -3 | -2 | -1 |

* **Positive indexing** starts from `0` and moves left to right.
* **Negative indexing** starts from `-1` at the last element and moves right to left.

#### Accessing elements using negative indexing
Negative indexing allows us to access elements from the end of a list.

```python
languages = ["Python", "Java", "C", "JavaScript"]

print(languages[-1])
print(languages[-2])
print(languages[-3])
print(languages[-4])
```

**Output:**
```text
JavaScript
C
Java
Python
```

**Important:** Accessing an index that does not exist produces an `IndexError`.
```python
numbers = [10, 20, 30]

print(numbers[5])
```

**Output:**
```text
IndexError: list index out of range
```

### 1.4 List Slicing
Slicing is used to extract a portion of a list.

**Syntax:**
```python
list_name[start : stop : step]
```

| Parameter | Meaning |
| :--- | :--- |
| `start` | Starting index (included) |
| `stop` | Ending index (excluded) |
| `step` | Number of positions to move |

**Example:**
```python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[1:4])
```

**Output:**
```text
[20, 30, 40]
```

**Explanation:**
* Starts from index 1.
* Stops before index 4.
* Includes elements at indices 1, 2, and 3.

#### Different slicing operations
```python
numbers = [10, 20, 30, 40, 50, 60]

print(numbers[0:3])
print(numbers[2:5])
print(numbers[:4])
print(numbers[2:])
print(numbers[:])
print(numbers[::2])
print(numbers[::-1])
```

**Output:**
```text
[10, 20, 30]
[30, 40, 50]
[10, 20, 30, 40]
[30, 40, 50, 60]
[10, 20, 30, 40, 50, 60]
[10, 30, 50]
[60, 50, 40, 30, 20, 10]
```

#### Understanding step values
```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]

print(numbers[::2])
print(numbers[1::2])
print(numbers[::-1])
print(numbers[::-2])
```

**Output:**
```text
[1, 3, 5, 7]
[2, 4, 6, 8]
[8, 7, 6, 5, 4, 3, 2, 1]
[8, 6, 4, 2]
```

> **Practical application:** Slicing is useful when selecting a range of records, extracting a subset of data, reversing sequences, and processing datasets.
