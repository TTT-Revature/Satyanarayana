## 4. Tuples

### 4.1 What is a Tuple?
A tuple is a built-in Python data structure used to store multiple elements in an ordered and immutable collection. Tuples are similar to lists, but their elements cannot be modified after creation.

**Characteristics:**
* Ordered.
* Immutable.
* Allows duplicate elements.
* Supports different data types.
* Supports indexing and slicing.
* Generally uses less memory than an equivalent list.

---

### 4.2 Creating Tuples

**Method 1: Using parentheses**
```python
numbers = (10, 20, 30, 40)

print(numbers)
```

**Output:**
```text
(10, 20, 30, 40)
```

**Method 2: Creating an empty tuple**
```python
t = ()

print(t)
```

**Output:**
```text
()
```

**Method 3: Creating a tuple without parentheses**
```python
numbers = 10, 20, 30

print(numbers)
```

**Output:**
```text
(10, 20, 30)
```

**Method 4: Using `tuple()`**
```python
numbers = tuple([10, 20, 30])

print(numbers)
```

**Output:**
```text
(10, 20, 30)
```

**Method 5: Creating a single-element tuple**
This is a particularly important case:
```python
a = (10,)

print(type(a))
```

**Output:**
```text
<class 'tuple'>
```

Without the comma:
```python
a = (10)

print(type(a))
```

**Output:**
```text
<class 'int'>
```
The trailing comma is what makes it a single-element tuple.

### 4.3 Accessing Tuple Elements
Tuples support both positive and negative indexing.
```python
languages = ("Python", "Java", "C", "JavaScript")

print(languages[0])
print(languages[-1])
```

**Output:**
```text
Python
JavaScript
```

---

### 4.4 Tuple Slicing
```python
numbers = (10, 20, 30, 40, 50)

print(numbers[1:4])
print(numbers[:3])
print(numbers[::-1])
```

**Output:**
```text
(20, 30, 40)
(10, 20, 30)
(50, 40, 30, 20, 10)
```

---

### 4.5 Tuple Methods
Tuples have only two built-in methods.

#### `count()`
Returns the number of times an element appears.
```python
numbers = (10, 20, 10, 30, 10)

print(numbers.count(10))
```

**Output:**
```text
3
```

#### `index()`
Returns the index of the first occurrence.
```python
numbers = (10, 20, 30, 20)

print(numbers.index(20))
```

**Output:**
```text
1
```

---

### 4.6 Tuple Immutability
Once a tuple is created, its elements cannot be changed.
```python
numbers = (10, 20, 30)

numbers[1] = 200
```

**Output:**
```text
TypeError: 'tuple' object does not support item assignment
```

However, if a tuple contains a mutable object such as a list, that inner object can be modified:
```python
data = (10, [20, 30], 40)

data[1].append(50)

print(data)
```

**Output:**
```text
(10, [20, 30, 50], 40)
```
The tuple's reference to the list remains unchanged, but the list itself is mutable.

### 4.7 Tuple Packing and Unpacking
* **Tuple packing:** Assigning multiple values to a tuple.
```python
student = "Rahul", 21, 85

print(student)
```

**Output:**
```text
('Rahul', 21, 85)
```

* **Tuple unpacking:** Assigning tuple elements to individual variables.
```python
student = ("Rahul", 21, 85)

name, age, marks = student

print(name)
print(age)
print(marks)
```

**Output:**
```text
Rahul
21
85
```
The number of variables must normally match the number of elements.

#### Extended unpacking
```python
numbers = (10, 20, 30, 40, 50)

first, *middle, last = numbers

print(first)
print(middle)
print(last)
```

**Output:**
```text
10
[20, 30, 40]
50
```

### 4.8 List vs Tuple

| Feature | List | Tuple |
| :--- | :--- | :--- |
| Syntax | `[]` | `()` |
| Mutable | Yes | No |
| Ordered | Yes | Yes |
| Duplicates | Allowed | Allowed |
| Indexing | Supported | Supported |
| Slicing | Supported | Supported |
| Methods | Many | Two |
| Typical use | Dynamic collections | Fixed collections |

**Practical applications of tuples:**
* Storing coordinates: `(10, 20)`.
* Storing dates: `(16, 11, 2026)`.
* Returning multiple values from functions.
* Representing fixed configuration data.
* Using immutable collections as dictionary keys when their elements are hashable.
