## 7. Nested Dictionaries and Data Structures

### 7.1 What is a Nested Dictionary?
A nested dictionary is a dictionary containing another dictionary as its value. It is useful when storing structured information about multiple entities.

**Example:**
```python
students = {
    "student1": {
        "name": "Rahul",
        "age": 21,
        "marks": 85
    },
    "student2": {
        "name": "Priya",
        "age": 22,
        "marks": 95
    }
}

print(students)
```
Here:
* `students` is the outer dictionary.
* `student1` and `student2` are outer keys.
* Their corresponding values are inner dictionaries.

---

### 7.2 Accessing Nested Dictionary Elements
We can access nested values using multiple keys.
```python
students = {
    "student1": {
        "name": "Rahul",
        "age": 21,
        "marks": 85
    },
    "student2": {
        "name": "Priya",
        "age": 22,
        "marks": 95
    }
}

print(students["student1"]["name"])
print(students["student2"]["marks"])
```

**Output:**
```text
Rahul
95
```

---

### 7.3 Updating Nested Dictionaries
```python
students = {
    "student1": {
        "name": "Rahul",
        "marks": 85
    }
}

students["student1"]["marks"] = 95

print(students)
```

**Output:**
```text
{'student1': {'name': 'Rahul', 'marks': 95}}
```

---

### 7.4 Adding New Nested Elements
```python
students = {
    "student1": {
        "name": "Rahul",
        "marks": 85
    }
}

students["student2"] = {
    "name": "Priya",
    "marks": 95
}

print(students)
```

---

### 7.5 Iterating Through Nested Dictionaries
```python
students = {
    "student1": {
        "name": "Rahul",
        "marks": 85
    },
    "student2": {
        "name": "Priya",
        "marks": 95
    }
}

for student_id, details in students.items():
    print("Student ID:", student_id)
    for key, value in details.items():
        print(key, ":", value)
```

**Output:**
```text
Student ID: student1
name : Rahul
marks : 85
Student ID: student2
name : Priya
marks : 95
```

---

### 7.6 Combining Different Data Structures
Python allows us to combine lists, tuples, sets, and dictionaries.

**Example:**
```python
students = [
    {
        "name": "Rahul",
        "subjects": ["Python", "Java", "SQL"],
        "marks": (85, 90, 88)
    },
    {
        "name": "Priya",
        "subjects": ["Python", "AI", "ML"],
        "marks": (95, 92, 96)
    }
]

print(students[0]["name"])
print(students[0]["subjects"][1])
print(students[1]["marks"][0])
```

**Output:**
```text
Rahul
Java
95
```
Here:
* The outer structure is a list.
* Each list element is a dictionary.
* `subjects` is a list.
* `marks` is a tuple.

#### Practical application: Employee management system
```python
employees = {
    101: {
        "name": "Rahul",
        "department": "IT",
        "salary": 50000,
        "skills": ["Python", "SQL", "Django"]
    },
    102: {
        "name": "Priya",
        "department": "AI",
        "salary": 60000,
        "skills": ["Python", "Machine Learning", "NLP"]
    }
}

for emp_id, details in employees.items():
    print("Employee ID:", emp_id)
    print("Name:", details["name"])
    print("Department:", details["department"])
    print("Skills:", details["skills"])
    print()
```
This structure is useful for employee records, student management systems, API responses, JSON data, and real-world applications.
