### 2.1 Important List Methods

#### 1. `append()`
Adds one element at the end of the list.
```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40]
```

**Note:** `append()` adds its argument as a single element.
```python
numbers = [10, 20]

numbers.append([30, 40])

print(numbers)
```

**Output:**
```text
[10, 20, [30, 40]]
```

#### 2. `extend()`
Adds multiple elements from another iterable to the existing list.
```python
numbers = [10, 20]

numbers.extend([30, 40, 50])

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40, 50]
```

**Difference between `append()` and `extend()`:**
```python
a = [1, 2]
a.append([3, 4])

b = [1, 2]
b.extend([3, 4])

print(a)
print(b)
```

**Output:**
```text
[1, 2, [3, 4]]
[1, 2, 3, 4]
```

#### 3. `insert()`
Inserts an element at a specified position.

**Syntax:**
```python
list.insert(index, element)
```

**Example:**
```python
numbers = [10, 20, 40]

numbers.insert(2, 30)

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40]
```

#### 4. `remove()`
Removes the first occurrence of a specified value.
```python
numbers = [10, 20, 30, 20, 40]

numbers.remove(20)

print(numbers)
```

**Output:**
```text
[10, 30, 20, 40]
```
If the value does not exist, Python raises a `ValueError`.

#### 5. `pop()`
Removes and returns an element from the list.
```python
numbers = [10, 20, 30, 40]

result = numbers.pop()

print(result)
print(numbers)
```

**Output:**
```text
40
[10, 20, 30]
```

We can also provide an index:
```python
numbers = [10, 20, 30, 40]

numbers.pop(1)

print(numbers)
```

**Output:**
```text
[10, 30, 40]
```

**Difference between `remove()` and `pop()`:**

| `remove()` | `pop()` |
| :--- | :--- |
| Removes a value | Removes an element by index |
| Returns `None` | Returns removed element |
| Raises `ValueError` if value is absent | Raises `IndexError` if index is invalid |

#### 6. `clear()`
Removes all elements from a list.
```python
numbers = [10, 20, 30]

numbers.clear()

print(numbers)
```

**Output:**
```text
[]
```

#### 7. `index()`
Returns the index of the first occurrence of an element.
```python
numbers = [10, 20, 30, 20]

print(numbers.index(20))
```

**Output:**
```text
1
```

#### 8. `count()`
Returns the number of occurrences of an element.
```python
numbers = [10, 20, 10, 30, 10]

print(numbers.count(10))
```

**Output:**
```text
3
```

#### 9. `reverse()`
Reverses the list in place.
```python
numbers = [10, 20, 30, 40]

numbers.reverse()

print(numbers)
```

**Output:**
```text
[40, 30, 20, 10]
```

#### 10. `copy()`
Creates a shallow copy of a list.
```python
numbers = [10, 20, 30]

new_numbers = numbers.copy()

print(new_numbers)
```

**Output:**
```text
[10, 20, 30]
```

### 2.2 List Sorting
Sorting means arranging elements in ascending or descending order.

Python provides two main approaches:
* `sort()` – Sorts the original list in place.
* `sorted()` – Returns a new sorted list.

#### `sort()` method
By default, it sorts in ascending order.
```python
numbers = [50, 10, 40, 20, 30]

numbers.sort()

print(numbers)
```

**Output:**
```text
[10, 20, 30, 40, 50]
```

#### Descending order
Use `reverse=True`:
```python
numbers = [50, 10, 40, 20, 30]

numbers.sort(reverse=True)

print(numbers)
```

**Output:**
```text
[50, 40, 30, 20, 10]
```

#### `sorted()` function
```python
numbers = [50, 10, 40, 20, 30]

new_numbers = sorted(numbers)

print(new_numbers)
print(numbers)
```

**Output:**
```text
[10, 20, 30, 40, 50]
[50, 10, 40, 20, 30]
```
The original list remains unchanged.

#### Sorting strings
```python
names = ["Rahul", "Arjun", "Priya", "Sneha"]

names.sort()

print(names)
```

**Output:**
```text
['Arjun', 'Priya', 'Rahul', 'Sneha']
```

#### Sorting using `key`
The `key` parameter allows us to define how elements should be sorted.

**Example:** Sorting strings according to their length.
```python
names = ["Python", "Java", "C", "JavaScript"]

names.sort(key=len)

print(names)
```

**Output:**
```text
['C', 'Java', 'Python', 'JavaScript']
```

#### Sorting a list of dictionaries
```python
students = [
    {"name": "Rahul", "marks": 85},
    {"name": "Priya", "marks": 95},
    {"name": "Arjun", "marks": 75}
]

students.sort(key=lambda student: student["marks"])

print(students)
```

**Output:**
```text
[
    {'name': 'Arjun', 'marks': 75},
    {'name': 'Rahul', 'marks': 85},
    {'name': 'Priya', 'marks': 95}
]
```
Here, `lambda` extracts the marks field to determine sorting order.

#### Time complexity of sorting
Python's sorting algorithm, **Timsort**, has:
* **Best case:** $O(n)$
* **Average case:** $O(n \log n)$
* **Worst case:** $O(n \log n)$
