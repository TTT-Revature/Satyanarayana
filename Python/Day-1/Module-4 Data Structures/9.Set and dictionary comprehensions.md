## 9. Set and Dictionary Comprehensions

Python supports comprehensions for sets and dictionaries as well. They allow us to create these data structures concisely using iterable data.

### 9.1 Set Comprehension
Set comprehension is used to create a set using a single expression.

**Syntax:**
```python
new_set = {expression for item in iterable}
```

**Example:**
```python
numbers = [1, 2, 2, 3, 3, 4, 5]

unique_squares = {n ** 2 for n in numbers}

print(unique_squares)
```

**Output:**
```text
{1, 4, 9, 16, 25}
```
Notice that duplicate results are automatically removed.

#### Set comprehension with conditions
**Example:** Extract even numbers.
```python
numbers = range(1, 11)

even_numbers = {
    n for n in numbers
    if n % 2 == 0
}

print(even_numbers)
```

**Output:**
```text
{2, 4, 6, 8, 10}
```

#### Converting strings into unique characters
```python
word = "programming"

unique_chars = {char for char in word}

print(unique_chars)
```
The result contains each character only once. Its display order is not guaranteed.

#### Practical application: Finding unique skills
```python
employees = [
    ["Python", "SQL", "Java"],
    ["Python", "Machine Learning"],
    ["SQL", "Python", "NLP"]
]

unique_skills = {
    skill
    for employee in employees
    for skill in employee
}

print(unique_skills)
```

**Output contains:**
```text
{'Python', 'SQL', 'Java', 'Machine Learning', 'NLP'}
```
*(Note: The ordering may vary.)*

---

### 9.2 Dictionary Comprehension
Dictionary comprehension creates a dictionary using a single expression.

**Syntax:**
```python
new_dict = {key_expression: value_expression for item in iterable}
```

#### Example 1: Creating a dictionary of squares
```python
numbers = [1, 2, 3, 4, 5]

squares = {
    n: n ** 2
    for n in numbers
}

print(squares)
```

**Output:**
```text
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```
Here, `Key` = Original number and `Value` = Square of the number.

#### Example 2: Dictionary comprehension with conditions
Extract even numbers and their squares.
```python
numbers = range(1, 11)

even_squares = {
    n: n ** 2
    for n in numbers
    if n % 2 == 0
}

print(even_squares)
```

**Output:**
```text
{2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
```

#### Example 3: Converting names into uppercase
```python
names = ["rahul", "priya", "arjun"]

result = {
    name: name.upper()
    for name in names
}

print(result)
```

**Output:**
```text
{
    'rahul': 'RAHUL',
    'priya': 'PRIYA',
    'arjun': 'ARJUN'
}
```

#### Example 4: Swapping keys and values
```python
student = {
    "name": "Rahul",
    "age": 21,
    "marks": 85
}

reversed_dict = {
    value: key
    for key, value in student.items()
}

print(reversed_dict)
```

**Output:**
```text
{'Rahul': 'name', 21: 'age', 85: 'marks'}
```
This works because the values in this example are hashable and unique. If multiple values are identical, later entries will overwrite earlier entries.

#### Example 5: Creating a dictionary from two lists
```python
names = ["Rahul", "Priya", "Arjun"]
marks = [85, 95, 75]

students = {
    names[i]: marks[i]
    for i in range(len(names))
}

print(students)
```

**Output:**
```text
{'Rahul': 85, 'Priya': 95, 'Arjun': 75}
```

An alternative is using `zip()`:
```python
students = {
    name: mark
    for name, mark in zip(names, marks)
}

print(students)
```
This is generally cleaner. `zip()` stops when the shortest iterable is exhausted.

### 9.3 Difference Between List, Set and Dictionary Comprehensions

| Feature | List | Set | Dictionary |
| :--- | :--- | :--- | :--- |
| Syntax | `[]` | `{}` | `{key: value}` |
| Stores | Elements | Unique elements | Key-value pairs |
| Duplicates | Allowed | Removed | Keys are unique |
| Ordering | Insertion order | No guaranteed order | Insertion order |
| Access | Index | Membership | Key |

#### Quick comparison
```python
numbers = [1, 2, 2, 3, 3, 4]

# List comprehension
a = [n * 2 for n in numbers]

# Set comprehension
b = {n * 2 for n in numbers}

# Dictionary comprehension
c = {n: n * 2 for n in numbers}

print(a)
print(b)
print(c)
```

**Output:**
```text
[2, 4, 4, 6, 6, 8]
{2, 4, 6, 8}
{1: 2, 2: 4, 3: 6, 4: 8}
```

## 10. Comparison of Python Collection Data Structures

This is one of the most important comparisons for interviews and examinations.

| Feature | List | Tuple | Set | Dictionary |
| :--- | :--- | :--- | :--- | :--- |
| Syntax | `[]` | `()` | `{}` | `{key: value}` |
| Ordered | Yes | Yes | No guaranteed order | Yes |
| Mutable | Yes | No | Yes | Yes |
| Duplicates | Allowed | Allowed | Not allowed | Keys cannot duplicate |
| Indexing | Yes | Yes | No | By key |
| Slicing | Yes | Yes | No | No |
| Main purpose | Collection of items | Fixed collection | Unique items | Key-value storage |

### 10.1 Choosing the Right Data Structure

| Requirement | Recommended Structure |
| :--- | :--- |
| Store a list of student names | List |
| Store fixed coordinates | Tuple |
| Store unique email addresses | Set |
| Store student details | Dictionary |
| Remove duplicate records | Set |
| Store ordered marks that may change | List |
| Represent a fixed RGB color | Tuple |
| Store employee ID and details | Dictionary |
| Find common elements | Set |
| Store API response data | Dictionary and lists |

```python
numbers = [1, 2, 2, 3, 3, 3, 4, 4]

frequency = {}

for number in numbers:
    if number in frequency:
        frequency[number] += 1
    else:
        frequency[number] = 1

```

**Output:**
```text
{1: 1, 2: 2, 3: 3, 4: 2}
```
*(This is a very common interview question.)*

### Program 6: Find students who scored above 80

```python
students = {
    "Rahul": 85,
    "Priya": 95,
    "Arjun": 65,

    name: marks
```


### Program 7: Flatten a nested list
```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
```
