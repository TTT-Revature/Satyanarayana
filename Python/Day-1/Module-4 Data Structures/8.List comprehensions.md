## 8. List Comprehensions

### 8.1 What is List Comprehension?
List comprehension is a concise way of creating a new list using an existing iterable. It allows us to write a `for` loop and optionally an `if` condition in a single expression.

**Normal approach:**
```python
squares = []

for i in range(1, 6):
    squares.append(i ** 2)

print(squares)
```

**Output:**
```text
[1, 4, 9, 16, 25]
```

**Using list comprehension:**
```python
squares = [i ** 2 for i in range(1, 6)]

print(squares)
```

**Output:**
```text
[1, 4, 9, 16, 25]
```
Both approaches produce the same result.

---

### 8.2 Syntax
```python
new_list = [expression for item in iterable]
```

| Component | Purpose |
| :--- | :--- |
| `expression` | Value to store in the new list |
| `item` | Variable representing each element |
| `iterable` | Source of elements |

---

### 8.3 List Comprehension with Conditions
We can include an `if` condition to filter elements.

**Syntax:**
```python
new_list = [expression for item in iterable if condition]
```

**Example:** Extract even numbers.
```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]

even_numbers = [n for n in numbers if n % 2 == 0]

print(even_numbers)
```

**Output:**
```text
[2, 4, 6, 8]
```

**Extract odd numbers:**
```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]

odd_numbers = [n for n in numbers if n % 2 != 0]

print(odd_numbers)
```

**Output:**
```text
[1, 3, 5, 7]
```

---

### 8.4 List Comprehension with `if-else`
When we want to choose between two values, we use an `if-else` expression.

**Syntax:**
```python
new_list = [value_if_true if condition else value_if_false for item in iterable]
```

**Example:**
```python
numbers = [1, 2, 3, 4, 5]

result = [
    "Even" if n % 2 == 0 else "Odd"
    for n in numbers
]

print(result)
```

**Output:**
```text
['Odd', 'Even', 'Odd', 'Even', 'Odd']
```

**Important distinction:**
* `if` after the `for` filters elements.
* `if-else` before the `for` selects what value to produce.

### 8.5 List Comprehension with Strings

**Example 1:** Convert names into uppercase.
```python
names = ["rahul", "priya", "arjun"]

upper_names = [name.upper() for name in names]

print(upper_names)
```

**Output:**
```text
['RAHUL', 'PRIYA', 'ARJUN']
```

**Example 2:** Extract words with more than four characters.
```python
words = ["Python", "Java", "C", "JavaScript"]

result = [word for word in words if len(word) > 4]

print(result)
```

**Output:**
```text
['Python', 'JavaScript']
```

### 8.6 Nested List Comprehension
A nested list comprehension can be used when processing nested iterables.

**Example:** Generate multiplication pairs.
```python
result = [
    (x, y)
    for x in range(1, 3)
    for y in range(1, 4)
]

print(result)
```

**Output:**
```text
[(1, 1), (1, 2), (1, 3), (2, 1), (2, 2), (2, 3)]
```

#### Flattening a nested list
```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

flattened = [
    element
    for row in matrix
    for element in row
]

print(flattened)
```

**Output:**
```text
[1, 2, 3, 4, 5, 6, 7, 8, 9]
```

### 8.7 Practical Example: Extracting Passing Students
```python
students = [
    {"name": "Rahul", "marks": 85},
    {"name": "Priya", "marks": 95},
    {"name": "Arjun", "marks": 30},
    {"name": "Sneha", "marks": 75}
]

passed_students = [
    student["name"]
    for student in students
    if student["marks"] >= 40
]

print(passed_students)
```

**Output:**
```text
['Rahul', 'Priya', 'Sneha']
```
This technique is particularly useful in data preprocessing and filtering.
