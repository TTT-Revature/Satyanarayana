# 1. Introduction to Python

## 1.1 What is Python?

Python is a **high-level, interpreted, general-purpose programming
language** known for its simple syntax, readability, and versatility.

It was created by **Guido van Rossum** and was first released in 1991.

Python allows programmers to write instructions in a human-readable
format without dealing with many low-level hardware details.

``` python
print("Hello, World!")
```

Output:

``` text
Hello, World!
```

## 1.2 Why is Python popular?

### 1. Simple and readable syntax

Python syntax resembles the English language, making it easier for
beginners to learn.

``` python
name = "Rahul"
age = 22

print("My name is", name)
print("My age is", age)
```

### 2. High-level programming language

A high-level language allows programmers to focus on solving problems
rather than managing hardware resources directly. Python automatically
manages memory allocation and deallocation.

### 3. Interpreted language

Python programs are executed through a Python runtime environment. The
standard CPython implementation compiles source code into bytecode and
executes it using the Python virtual machine.

### 4. Dynamically typed language

We do not need to explicitly declare a variable's data type.

``` python
x = 10
x = "Python"
x = 10.5
```

The same variable name can refer to objects of different types at
different points in the program.

### 5. Object-oriented language

Python supports classes, objects, inheritance, encapsulation,
polymorphism, and abstraction.

### 6. Cross-platform language

Python programs can run on Windows, Linux, and macOS.

### 7. Extensive library support

## 1.3 Applications of Python

-   **Web development:** Websites, web applications, and REST APIs using
    Django, Flask, and FastAPI.
-   **Artificial intelligence and machine learning:** Prediction models,
    chatbots, recommendation systems, and intelligent applications.
-   **Data science:** Data cleaning, analysis, visualization, and
    statistical modeling.
-   **Automation:** File handling, report generation, and web scraping.
-   **Cybersecurity:** Network scanning, security testing, log analysis,
    and security automation.
