# 3. Python Interpreter and Running Python Programs

## 3.1 What is an interpreter?

An interpreter is a program that executes instructions written in a
programming language.

Python programs are commonly executed using the Python interpreter. The
interpreter reads and processes the program and performs the required
operations.

Python's standard implementation, CPython, follows this simplified
execution process:

``` text
Python Source Code (.py)
          |
          v
Compilation into bytecode
          |
          v
Python Bytecode
          |
          v
Python Virtual Machine (PVM)
          |
          v
Program Output
```

This is a simplified explanation of CPython. Other Python
implementations may use different execution mechanisms.

## 3.2 What is bytecode?

Bytecode is an intermediate representation of Python code. It is not the
same as machine code. The Python interpreter executes this bytecode
using its virtual machine.

``` python
a = 10
b = 20

print(a + b)
```

You can inspect bytecode using the `dis` module:

``` python
import dis

def add(a, b):
    return a + b

dis.dis(add)
```

This displays the bytecode instructions generated for the function.

## 3.3 Different ways to run Python programs

### Method 1: Interactive mode

Interactive mode allows us to execute Python statements directly in the
terminal.

Open Command Prompt and type:

``` bash
python
```

You will see the Python prompt:

``` text
>>>
```

Now execute:

``` python
>>> 10 + 20
30

>>> print("Hello Python")
Hello Python

>>> name = "Rahul"
>>> print(name)
Rahul
```

The `>>>` symbol indicates that Python is ready to receive an
instruction.

Exit using:

``` python
exit()
```

**When to use:** Testing small statements, calculations, and individual
Python concepts.

### Method 2: Script mode

In script mode, we write Python instructions in a file with the `.py`
extension.

Create `addition.py`:

``` python
a = 10
b = 20

result = a + b

print("Addition:", result)
```

Run the file:

``` bash
python addition.py
```

Output:

``` text
Addition: 30
```

**When to use:** Developing complete programs, applications, and
reusable code.

### Method 3: Notebook mode

Jupyter Notebook allows us to write and execute code in individual
cells.

Cell 1:

``` python
a = 10
b = 20
```

Cell 2:

``` python
print(a + b)
```

Output:

``` text
30
```

**When to use:** Data science, machine learning, experimentation, and
visualization.

## 3.4 Interactive mode vs. script mode

  Interactive mode                   Script mode
  ---------------------------------- -----------------------------------------
  Executes statements individually   Executes instructions from a file
  Uses Python prompt                 Uses `.py` files
  Suitable for quick testing         Suitable for complete programs
  Results appear immediately         Results appear when the script executes
  Usually not saved automatically    Code is saved in a file

## 3.5 Python command-line arguments

Python programs can accept information from the command line.

``` python
import sys

print("Program name:", sys.argv[0])
print("Arguments:", sys.argv[1:])
```

Run:

``` bash
python app.py Rahul 25
```

The program receives command-line arguments as strings.
