# 6. Variables and Naming Conventions

## 6.1 What is a variable?

A variable is a name that refers to an object stored in memory. It
allows us to store and reuse data throughout a program.

For example:

``` python
name = "Rahul"
age = 22
marks = 85.5

print(name)
print(age)
print(marks)
```

Output:

``` text
Rahul
22
85.5
```

Here, `name` refers to a string object, `age` to an integer object, and
`marks` to a floating-point object.

## 6.2 How to create a variable?

Python does not require an explicit declaration of variables. We create
a variable by assigning a value using the assignment operator (`=`).

Syntax:

``` python
variable_name = value
```

Examples:

``` python
x = 10
name = "Python"
price = 99.50
is_active = True
```

Python automatically determines the type of the assigned object.

Comparison with Java:

``` java
int age = 22;
String name = "Rahul";
```

Python:

``` python
age = 22
name = "Rahul"
```

## 6.3 Variable assignment

### A. Single assignment

``` python
x = 10
```

### B. Multiple assignments

``` python
a, b, c = 10, 20, 30

print(a)
print(b)
print(c)
```

Output:

``` text
10
20
30
```

### C. Assigning the same value to multiple variables

``` python
a = b = c = 100

print(a, b, c)
```

Output:

``` text
100 100 100
```

### D. Swapping variables

``` python
a = 10
b = 20

a, b = b, a

print(a)
print(b)
```

Output:

``` text
20
10
```

This is called multiple assignment or tuple unpacking.

## 6.4 Dynamic typing

Python is dynamically typed. A variable can refer to objects of
different data types during program execution.

``` python
x = 10
print(x)

x = "Hello"
print(x)

x = 10.5
print(x)
```

Output:

``` text
10
Hello
10.5
```

Important distinction: Python variables are names bound to objects. When
we reassign `x`, Python makes it refer to another object. It does not
change the original integer object into a string.

## 6.5 Rules for naming variables

  -----------------------------------------------------------------------
  Rule                                Example
  ----------------------------------- -----------------------------------
  Must start with a letter or         `name`, `_age`
  underscore                          

  Cannot start with a number          `1name` is invalid

  Can contain letters, numbers,       `student_1`
  underscores                         

  Cannot contain spaces               `student name` is invalid

  Cannot contain special characters   `total$` is invalid
  such as `@`, `$`, `%`               

  Variable names are case-sensitive   `age` and `Age` are different

  Cannot use Python keywords          `class`, `if`, `for` are invalid
  -----------------------------------------------------------------------

Valid names:

``` python
name = "Rahul"
student_age = 22
_marks = 90
total_marks_2026 = 450
```

Invalid names:

``` python
1name = "Rahul"       # Starts with a number
student age = 22      # Contains a space
class = "MTech"       # Python keyword
total-marks = 450     # Contains a hyphen
```

## 6.6 Python naming conventions

  Naming convention           Example            Usage
  --------------------------- ------------------ -------------------------
  Snake case                  `student_name`     Variables and functions
  Pascal case                 `StudentDetails`   Classes
  Uppercase                   `MAX_LIMIT`        Constants
  Leading underscore          `_salary`          Internal-use convention
  Double leading underscore   `__balance`        Class name mangling

### Snake case

``` python
student_name = "Rahul"
total_marks = 450
```

### Pascal case

``` python
class StudentDetails:
    pass
```

### Uppercase naming

``` python
PI = 3.14159
MAX_ATTEMPTS = 3
DATABASE_NAME = "college"
```

Python does not enforce constants. These are naming conventions that
tell programmers not to modify the values.

## 6.7 Python keywords

Keywords are reserved words that have predefined meanings in Python.

Examples include `if`, `else`, `elif`, `for`, `while`, `def`, `class`,
`return`, `try`, `except`, `import`, `True`, `False`, and `None`.

To see all Python keywords:

``` python
import keyword

print(keyword.kwlist)
```

To check whether a word is a keyword:

``` python
import keyword

print(keyword.iskeyword("class"))
print(keyword.iskeyword("name"))
```

Output:

``` text
True
False
```

## 6.8 Variables and memory

``` python
a = 10
b = 10

print(a == b)
print(a is b)
```

Output in typical CPython execution:

``` text
True
True
```

-   `==` checks whether two objects have equal values.
-   `is` checks whether two references point to the same object.

In CPython, small integers are commonly cached, which explains why this
particular example often returns `True` for both comparisons. Do not
rely on object identity for ordinary value comparisons.

**Important:** Use `==` when comparing values and `is` when checking
object identity, particularly with `None`.
