# 4. Python Syntax and Indentation

## 4.1 What is syntax?

Syntax refers to the rules and structure used to write valid
instructions in a programming language.

Valid Python:

``` python
print("Hello World")
```

Incorrect Python:

``` python
print("Hello World"
```

This causes a `SyntaxError` because the closing parenthesis is missing.

## 4.2 Python is case-sensitive

Python treats uppercase and lowercase letters as different characters.

``` python
name = "Rahul"
Name = "Ravi"

print(name)
print(Name)
```

Output:

``` text
Rahul
Ravi
```

`name` and `Name` are two different variables.

Similarly, `print("Hello")` is valid, but `Print("Hello")` causes an
error because Python does not recognize `Print` as the built-in
function.

## 4.3 Statements

A statement is an instruction executed by Python.

``` python
x = 10
y = 20
print(x + y)
```

This program contains three statements. Python generally identifies the
end of a statement using a newline.

Semicolons are not required, although they can separate simple
statements on one line:

``` python
a = 10; b = 20; print(a + b)
```

This is valid but not recommended for normal programming.

## 4.4 Indentation

Indentation refers to the spaces at the beginning of a line of code.
Python uses indentation to define code blocks.

Unlike languages such as C and Java, Python does not use curly braces
`{}` to define blocks.

``` python
age = 20

if age >= 18:
    print("You are eligible to vote")
    print("You are an adult")

print("Program completed")
```

Output:

``` text
You are eligible to vote
You are an adult
Program completed
```

The two indented statements belong to the `if` block. The final
statement is outside the block.

## 4.5 Standard indentation rules

Python recommends using four spaces for each indentation level.

``` python
if True:
    print("Level 1")

    if True:
        print("Level 2")

        if True:
            print("Level 3")
```

Each nested block adds another indentation level.

## 4.6 IndentationError

Incorrect indentation produces an error.

Incorrect:

``` python
if True:
print("Hello")
```

This causes:

``` text
IndentationError: expected an indented block
```

Correct:

``` python
if True:
    print("Hello")
```

Inconsistent indentation can also produce an `IndentationError` or
`TabError`.

## 4.7 Colon in Python

A colon (`:`) introduces a compound statement block.

``` python
if age > 18:
    print("Adult")
```

``` python
for i in range(5):
    print(i)
```

``` python
def greet():
    print("Hello")
```

``` python
class Student:
    pass
```

Whenever a statement introduces a new block, such as `if`, `for`,
`while`, `def`, or `class`, it generally needs a colon followed by an
indented block.

## 4.8 Line continuation

Long statements can continue across multiple lines.

Using parentheses:

``` python
total = (
    10 +
    20 +
    30
)

print(total)
```

Using a backslash:

``` python
total = 10 + \
        20 + \
        30
```

Using parentheses is generally preferred.
