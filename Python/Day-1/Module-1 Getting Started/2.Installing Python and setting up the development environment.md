# 2. Installing Python and Setting Up the Development Environment

## 2.1 What is a development environment?

A development environment is a collection of software tools used to
write, execute, debug, and test programs.

A basic Python development environment consists of:

1.  Python interpreter
2.  Code editor or IDE
3.  Terminal or command prompt
4.  Python packages and libraries

## 2.2 Installing Python on Windows

1.  Visit the [official Python downloads
    page](https://www.python.org/downloads/).
2.  Download the latest stable Python version compatible with your
    system.
3.  Open the downloaded installer.
4.  Select **Add Python to PATH**.
5.  Click **Install Now** and wait for installation to complete.

### Verify the installation

Open Command Prompt and execute:

``` bash
python --version
```

Alternatively:

``` bash
py --version
```

Expected output (the version may differ):

``` text
Python 3.x.x
```

### Verify pip

``` bash
pip --version
```

`pip` is Python's package installer. It allows us to install external
libraries.

``` bash
pip install numpy
```

## 2.3 Setting up Visual Studio Code

[Visual Studio Code](https://code.visualstudio.com/) is a popular code
editor for Python development.

Steps:

1.  Download and install VS Code.
2.  Open VS Code.
3.  Navigate to Extensions.
4.  Search for **Python**.
5.  Install the Microsoft Python extension.
6.  Open a folder for your Python programs.
7.  Create a file named `hello.py`.
8.  Write your first Python program:

``` python
print("Welcome to Python Programming")
```

Run the file from the terminal:

``` bash
python hello.py
```

## 2.4 What is an IDE?

IDE stands for **Integrated Development Environment**. It provides tools
that help programmers develop applications in one place.

Examples:

  Editor/IDE         Main purpose
  ------------------ ----------------------------------
  IDLE               Basic Python learning
  VS Code            General Python development
  PyCharm            Professional Python development
  Jupyter Notebook   Data science and experimentation
  Spyder             Scientific computing

## 2.5 What is pip?

`pip` is a package management tool used to install and manage Python
packages.

``` bash
pip install numpy
```

Check installed packages:

``` bash
pip list
```

Uninstall a package:

``` bash
pip uninstall numpy
```

## 2.6 What is a virtual environment?

A virtual environment is an isolated Python environment that maintains
separate packages and dependencies for an individual project.

For example:

-   Project A requires Django 4.
-   Project B requires Django 5.

Virtual environments help avoid dependency conflicts between projects.

### Create a virtual environment

``` bash
python -m venv myenv
```

### Activate on Windows

``` bash
myenv\Scripts\activate
```

### Activate on Linux/macOS

``` bash
source myenv/bin/activate
```

### Install a package

``` bash
pip install flask
```

### Deactivate

``` bash
deactivate
```

### Remember the difference

-   **Python:** Executes Python programs.
-   **pip:** Installs Python packages.
-   **VS Code:** Provides an environment to write and manage code.
-   **Virtual environment:** Isolates dependencies for projects.
