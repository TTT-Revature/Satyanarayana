# 10. `type()` and Basic Object Inspection

## 10.1 What is the `type()` function?

The `type()` function is a built-in Python function used to identify the
data type or class of an object.

Syntax:

``` python
type(object)
```

Example:

``` python
a = 10
b = 10.5
c = "Python"
d = True
e = [1, 2, 3]

print(type(a))
print(type(b))
print(type(c))
print(type(d))
print(type(e))
```

Output:

``` text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'list'>
```

Python displays the type in the format `<class 'type_name'>` because
built-in data types are classes, and their values are objects created
from those classes.

## 10.2 Checking different data types


## 10.3 Difference between `type()` and `isinstance()`

Both are used to check object types, but they behave differently.

Using `type()`:

``` python
x = 10

print(type(x) == int)
```

Output:

``` text
True
```

Using `isinstance()`:

``` python
x = 10

print(isinstance(x, int))
```

Output:

``` text
True
```

The important difference appears when inheritance is involved:

``` python
class Animal:
    pass

class Dog(Animal):
    pass

d = Dog()

print(type(d) == Animal)
print(isinstance(d, Animal))
```

Output:

``` text
False
True
```

-   `type(d)` returns the actual class of the object, which is `Dog`.
-   `isinstance(d, Animal)` checks whether the object is an instance of
    `Animal` or one of its subclasses.

**Best practice:** Use `isinstance()` when checking whether an object
belongs to a type or its subclasses.

## 10.4 What is `id()`?

The `id()` function returns an object's identity. It is an integer that
uniquely identifies an object during its lifetime.

``` python
x = 100

print(id(x))
```

The actual output will vary.

Consider two variables:

``` python
a = [10, 20, 30]
b = a

print(id(a))
print(id(b))
```

Both values will be the same because both variables refer to the same
list object.

Now consider:

``` python
a = [10, 20, 30]
b = [10, 20, 30]

print(a == b)
print(a is b)
```

Output:

``` text
True
False
```

-   `==` compares values.
-   `is` compares object identity.
-   `id()` provides the identity value of an object.

## 10.5 What is `dir()`?

The `dir()` function returns a list of names associated with an object.
These names include available attributes and methods.

``` python
name = "Python"

print(dir(name))
```

The result includes methods such as `upper`, `lower`, `split`,
`replace`, `capitalize`, `startswith`, and `endswith`.

Inspect list methods:

``` python
numbers = [10, 20, 30]

print(dir(numbers))
```

The result includes methods such as `append`, `extend`, `insert`,
`remove`, `pop`, `sort`, and `reverse`.

This is useful when learning an unfamiliar Python object.

## 10.6 What is `help()`?

The `help()` function provides documentation about Python objects,
classes, functions, and modules.

``` python
help(str)
```

For a particular method:

``` python
help(str.upper)
```

For a list method:

``` python
help(list.append)
```

## 10.7 What is the `__dict__` attribute?

Many Python objects have a `__dict__` attribute that stores their
instance attributes.

``` python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

s1 = Student("Rahul", 22)

print(s1.__dict__)
```

Output:

``` text
{'name': 'Rahul', 'age': 22}
```

Not every object has a `__dict__`. Some classes use `__slots__`, and
built-in objects such as lists do not generally expose an instance
`__dict__`.

## 10.8 Important object inspection functions

  ---------------------------------------------------------------------------
  Function/attribute      Purpose                 Example
  ----------------------- ----------------------- ---------------------------
  `type()`                Returns the object's    `type(10)`
                          type                    

  `id()`                  Returns object identity `id(x)`

  `isinstance()`          Checks type             `isinstance(x, int)`
                          compatibility           

  `issubclass()`          Checks class            `issubclass(Dog, Animal)`

                          `__dict__` when         
                          available               

  `hasattr()`             Checks whether an       `hasattr(obj, "name")`
                          attribute exists        

  `getattr()`             Retrieves an attribute  `getattr(obj, "name")`
  ---------------------------------------------------------------------------

### Practical example: Inspecting an object

``` python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student = Student("Rahul", 22)

print(type(student))
print(id(student))
print(isinstance(student, Student))
print(dir(student))
print(vars(student))
print(hasattr(student, "name"))
print(getattr(student, "name"))
```

This example combines several object inspection functions.
