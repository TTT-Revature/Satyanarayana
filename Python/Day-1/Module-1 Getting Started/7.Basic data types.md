# 7. Basic Data Types in Python

## 7.1 What is a data type?

A data type defines the kind of value an object represents and the
operations that can be performed on it.

For example:

-   `10` represents an integer.
-   `10.5` represents a floating-point number.
-   `"Python"` represents text.
-   `True` represents a Boolean value.

## 7.2 Classification of Python data types

  Category   Built-in types
  ---------- ------------------------------------
  Numeric    `int`, `float`, `complex`
  Sequence   `str`, `list`, `tuple`, `range`
  Mapping    `dict`
  Set        `set`, `frozenset`
  Boolean    `bool`
  Binary     `bytes`, `bytearray`, `memoryview`
  None       `NoneType`

## 7.3 Numeric data types

Python provides three main numeric types.

### A. Integer (`int`)

An integer represents a whole number without a decimal component.

``` python
a = 10
b = -25
c = 0

print(a)
print(b)
print(c)
print(type(a))
```

Output:

``` text
10
-25
0
<class 'int'>
```

Python integers can grow beyond the fixed-width limits of typical 32-bit
or 64-bit integer types, subject to available memory.

Real-world examples: number of students, employees, product quantity,
and age.

### B. Floating-point (`float`)

A float represents a number with a decimal component.

``` python
price = 99.99
temperature = 36.5
percentage = 85.75

print(price)
print(type(price))
```

Output:

``` text
99.99
<class 'float'>
```

Floating-point values are generally represented using binary
floating-point arithmetic. Some decimal values cannot be represented
exactly.

``` python
a = 0.1
b = 0.2

print(a + b)
```

Output:

``` text
0.30000000000000004
```

This is a consequence of floating-point representation, not necessarily
a programming error. For precise financial calculations, Python provides
the `decimal` module.

### C. Complex (`complex`)

Complex numbers contain a real part and an imaginary part.

\[ z = a + bj \]

Here, `a` is the real part, `b` is the imaginary part, and `j`
represents the imaginary unit.

``` python
z = 3 + 4j

print(z)
print(z.real)
print(z.imag)
print(type(z))
```

Output:

``` text
(3+4j)
3.0
4.0
<class 'complex'>
```

Applications include engineering calculations, scientific computing, and
signal processing.

## 7.4 String (`str`)

A string is a sequence of Unicode characters used to represent text.

Strings can be written using single quotes, double quotes, triple single
quotes, or triple double quotes.

``` python
name = 'Rahul'
city = "Hyderabad"

message = """Welcome
to Python
Programming"""

print(name)
print(city)
print(message)
```

Output:

``` text
Rahul
Hyderabad
Welcome
to Python
Programming
```

### String indexing

Python uses zero-based indexing.

``` python
name = "PYTHON"

print(name[0])
print(name[1])
print(name[5])
```

Output:

``` text
P
Y
N
```

Index positions:

  Character           P    Y    T    H    O    N
  ---------------- ---- ---- ---- ---- ---- ----
  Positive index      0    1    2    3    4    5
  Negative index     -6   -5   -4   -3   -2   -1

Negative indexing starts from the end:

``` python
name = "PYTHON"

print(name[-1])
print(name[-2])
```

Output:

``` text
N
O
```

### String slicing

Slicing extracts a portion of a string.

Syntax:

``` python
string[start:stop:step]
```

Example:

``` python
name = "PYTHON"

print(name[0:3])
print(name[2:5])
print(name[::-1])
```

Output:

``` text
PYT
THO
NOHTYP
```

The stop index is excluded.

### Common string methods

``` python
text = "python programming"

print(text.upper())
print(text.lower())
print(text.title())
print(text.capitalize())
print(text.replace("python", "Java"))
print(text.startswith("python"))
print(text.endswith("programming"))
```

### String concatenation

Combining two strings is called concatenation.

``` python
first_name = "Rahul"
last_name = "Kumar"

full_name = first_name + " " + last_name

print(full_name)
```

Output:

``` text
Rahul Kumar
```

### String repetition

``` python
print("Python " * 3)
```

Output:

``` text
Python Python Python
```

### String formatting

Formatted strings, commonly called f-strings, allow variables and
expressions to be embedded in strings.

``` python
name = "Rahul"
age = 22

print(f"My name is {name} and I am {age} years old.")
```

Output:

``` text
My name is Rahul and I am 22 years old.
```

## 7.5 List (`list`)

A list is an ordered, mutable collection of elements. It can store
elements of different data types. Lists are created using square
brackets `[]`.

``` python
students = ["Rahul", "Ravi", "Priya"]

print(students)
print(students[0])
```

Output:

``` text
['Rahul', 'Ravi', 'Priya']
Rahul
```

A list can contain mixed data types:

``` python
data = [10, "Python", 85.5, True]

print(data)
```

### Adding elements

``` python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

Output:

``` text
[10, 20, 30, 40]
```

### Inserting elements

``` python
numbers = [10, 20, 30]

numbers.insert(1, 15)

print(numbers)
```

Output:

``` text
[10, 15, 20, 30]
```

### Removing elements

``` python
numbers = [10, 20, 30]

numbers.remove(20)

print(numbers)
```

Output:

``` text
[10, 30]
```

### Modifying elements

``` python
numbers = [10, 20, 30]

numbers[0] = 100

print(numbers)
```

Output:

``` text
[100, 20, 30]
```

Real-world applications: student records, shopping cart items, employee
details, and collections of data.

## 7.6 Tuple (`tuple`)

A tuple is an ordered, immutable collection of elements. Tuples are
generally created using parentheses `()`.

``` python
student = ("Rahul", 22, "M.Tech")

print(student)
print(student[0])
print(student[1])
```

Output:

``` text
('Rahul', 22, 'M.Tech')
Rahul
22
```

Tuple elements cannot be reassigned:

``` python
numbers = (10, 20, 30)

# This causes TypeError:
numbers[0] = 100
```

### Single-element tuple

A tuple containing one element requires a trailing comma.

``` python
a = (10,)

print(type(a))
```

Output:

``` text
<class 'tuple'>
```

Without the comma:

``` python
a = (10)

print(type(a))
```

Output:

``` text
<class 'int'>
```

Applications: fixed coordinates, database records, returning multiple
values from a function, and fixed configuration values.

## 7.7 Set (`set`)

A set is an unordered collection of unique elements. Sets are created
using curly braces `{}` or the `set()` constructor.

``` python
numbers = {10, 20, 30, 20, 10}

print(numbers)
```

Output (display order may vary):

``` text
{10, 20, 30}
```

Duplicate elements are automatically removed.

### Adding elements

``` python
numbers = {10, 20, 30}
numbers.add(40)

print(numbers)
```

### Removing elements

``` python
numbers = {10, 20, 30}
numbers.remove(20)

print(numbers)
```

### Set operations

**Union:** Combines elements from both sets.

``` python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
```

Output:

``` text
{1, 2, 3, 4, 5}
```

**Intersection:** Returns common elements.

``` python
print(a & b)
```

Output:

``` text
{3}
```

**Difference:** Returns elements present in the first set but not the
second.

``` python
print(a - b)
```

Output:

``` text
{1, 2}
```

Applications: removing duplicate records, finding common students, and
comparing datasets.

## 7.8 Dictionary (`dict`)

A dictionary stores data in key-value pairs and is created using curly
braces `{}`.

``` python
student = {
    "name": "Rahul",
    "age": 22,
    "course": "M.Tech",
    "marks": 85
}

print(student)
print(student["name"])
print(student["age"])
```

Output:

``` text
{'name': 'Rahul', 'age': 22, 'course': 'M.Tech', 'marks': 85}
Rahul
22
```

### Adding a key-value pair

``` python
student["city"] = "Hyderabad"

print(student)
```

### Updating a value

``` python
student["age"] = 23

print(student["age"])
```

### Removing a key

``` python
del student["marks"]

print(student)
```

### Accessing dictionary information

``` python
print(student.keys())
print(student.values())
print(student.items())
```

Important characteristics:

-   Dictionary keys must be unique.
-   Dictionary keys must be hashable.
-   Dictionary values can be of different types.
-   Dictionaries preserve insertion order in modern Python.

Applications: JSON data, API responses, employee records, configuration
settings, and database-like structures.

## 7.9 Boolean (`bool`)

Boolean represents one of two logical values: `True` or `False`.

``` python
is_student = True
is_employed = False

print(is_student)
print(type(is_student))
```

Output:

``` text
True
<class 'bool'>
```

Boolean values are commonly used in conditional statements.

``` python
age = 20

is_adult = age >= 18

print(is_adult)
```

Output:

``` text
True
```

## 7.10 Range (`range`)

The `range` type represents an immutable sequence of integers, commonly
used in loops.

Syntax:

``` python
range(start, stop, step)
```

Example:

``` python
numbers = range(1, 6)

print(list(numbers))
```

Output:

``` text
[1, 2, 3, 4, 5]
```

The stop value is excluded.

``` python
for i in range(1, 6):
    print(i)
```

Output:

``` text
1
2
3
4
5
```

## 7.11 NoneType

`None` represents the absence of a value. It is Python's null-like
value.

``` python
result = None

print(result)
print(type(result))
```

Output:

``` text
None
<class 'NoneType'>
```

A common use case is a function that does not return a meaningful
result.

``` python
def greet():
    print("Hello")

result = greet()

print(result)
```

Output:

``` text
Hello
None
```

The function prints a message but does not explicitly return a value.
Python returns `None` automatically.

## 7.12 Binary data types

Python provides three important binary-related types.

  -----------------------------------------------------------------------
  Type                    Description             Mutable?
  ----------------------- ----------------------- -----------------------
  `bytes`                 Immutable sequence of   No
                          bytes                   

  `bytearray`             Mutable sequence of     Yes
                          bytes                   

  `memoryview`            View of binary data     Depends on underlying
                          without copying it      object
  -----------------------------------------------------------------------

### Bytes

``` python
a = bytes([65, 66, 67])

print(a)
print(type(a))
```

Output:

``` text
b'ABC'
<class 'bytes'>
```

### Bytearray

``` python
b = bytearray([65, 66, 67])

b[0] = 90

print(b)
```

Output:

``` text
bytearray(b'ZBC')
```

### Memoryview

``` python
data = bytearray(b"Python")

view = memoryview(data)

print(view[0])
```

Output:

``` text
80
```

These types are useful in file processing, networking, and handling
binary data.
