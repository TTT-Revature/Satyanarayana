# 9. Type Conversion

## 9.1 What is type conversion?

Type conversion means changing a value from one data type to another.

Examples include integer to string, string to integer, float to integer,
and integer to float.

Python supports two types of conversion:

1.  Implicit type conversion
2.  Explicit type conversion

## 9.2 Implicit type conversion

Implicit conversion happens automatically when Python converts one data
type into another during an operation.

``` python
a = 10
b = 2.5

result = a + b

print(result)
print(type(result))
```

Output:

``` text
12.5
<class 'float'>
```

Python automatically converts the integer to a float for the arithmetic
operation. The result is a float.

Another example:

``` python
a = 5
b = 2.0

print(a + b)
```

Output:

``` text
7.0
```

## 9.3 Explicit type conversion

Explicit conversion happens when the programmer manually converts a
value using built-in conversion functions. It is also called type
casting.

### A. `int()`

Converts compatible values into integers.

``` python
a = int(10.8)
b = int("100")

print(a)
print(b)
```

Output:

``` text
10
100
```

`int()` truncates the decimal part rather than rounding it.

``` python
print(int(9.9))
print(int(-9.9))
```

Output:

``` text
9
-9
```

Invalid conversion:

``` python
a = int("Python")
```

This raises a `ValueError`.

### B. `float()`

Converts compatible values into floating-point numbers.

``` python
a = float(10)
b = float("25.5")

print(a)
print(b)
```

Output:

``` text
10.0
25.5
```

### C. `str()`

Converts a value into a string representation.

``` python
age = 22

result = str(age)

print(result)
print(type(result))
```

Output:

``` text
22
<class 'str'>
```

This is useful when combining numbers with text:

``` python
age = 22

print("My age is " + str(age))
```

Output:

``` text
My age is 22
```

### D. `bool()`

Converts a value into a Boolean.

``` python
print(bool(1))
print(bool(0))
print(bool(""))
print(bool("Python"))
```

Output:

``` text
True
False
False
True
```

Common falsy values:

  Value       Boolean result
  ----------- ----------------
  `0`         `False`
  `0.0`       `False`
  `""`        `False`
  `[]`        `False`
  `{}`        `False`
  `()`        `False`
  `None`      `False`
  `1`         `True`
  `"Hello"`   `True`
  `[1, 2]`    `True`

Empty collections and zero-like values are called falsy values. Most
other objects are truthy.

### E. `list()`

Converts an iterable into a list.

``` python
a = (10, 20, 30)

result = list(a)

print(result)
```

Output:

``` text
[10, 20, 30]
```

String conversion:

``` python
print(list("Python"))
```

Output:

``` text
['P', 'y', 't', 'h', 'o', 'n']
```

### F. `tuple()`

Converts an iterable into a tuple.

``` python
a = [10, 20, 30]

result = tuple(a)

print(result)
```

Output:

``` text
(10, 20, 30)
```

### G. `set()`

Converts an iterable into a set.

``` python
numbers = [10, 20, 10, 30, 20]

result = set(numbers)

print(result)
```

Output (display order may vary):

``` text
{10, 20, 30}
```

### H. `dict()`

Creates a dictionary from suitable key-value pairs.

``` python
data = [
    ("name", "Rahul"),
    ("age", 22)
]

result = dict(data)

print(result)
```

Output:

``` text
{'name': 'Rahul', 'age': 22}
```

## 9.4 Type conversion summary

  Function        Conversion      Example
  --------------- --------------- -----------------------
  `int()`         To integer      `int("10")`
  `float()`       To float        `float("10.5")`
  `str()`         To string       `str(100)`
  `bool()`        To Boolean      `bool(1)`
  `list()`        To list         `list((1, 2))`
  `tuple()`       To tuple        `tuple([1, 2])`
  `set()`         To set          `set([1, 2, 2])`
  `dict()`        To dictionary   `dict([("a", 1)])`
  `complex()`     To complex      `complex(2, 3)`
  `bytes()`       To bytes        `bytes([65, 66])`
  `bytearray()`   To bytearray    `bytearray([65, 66])`

## 9.5 Type conversion in user input

One important concept for beginners is understanding the `input()`
function.

By default, `input()` returns a string.

``` python
age = input("Enter your age: ")

print(type(age))
```

If the user enters `22`, the output is:

``` text
<class 'str'>
```

Even though the user entered a number, Python treats it as a string.

If we want to perform mathematical calculations, we must convert it:

``` python
age = int(input("Enter your age: "))

print(age + 5)
```

Input:

``` text
22
```

Output:

``` text
27
```

Without conversion:

``` python
num1 = input("Enter first number: ")
num2 = input("Enter second number: ")

print(num1 + num2)
```

Input:

``` text
10
20
```

Output:

``` text
1020
```

Both values are strings, so Python performs string concatenation instead
of numerical addition.

Correct approach:

``` python
num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

print("Sum:", num1 + num2)
```

Input:

``` text
10
20
```

Output:

``` text
Sum: 30
```

## 9.6 Handling conversion errors

Invalid values may produce exceptions.

``` python
age = int(input("Enter your age: "))
```

If the user enters `hello`, Python raises a `ValueError`.

A safer approach is:

``` python
try:
    age = int(input("Enter your age: "))
    print("Age:", age)

except ValueError:
    print("Please enter a valid integer.")
```

This prevents the program from terminating unexpectedly due to invalid
integer input.
