# 11. Introduction to Type Hints

## 11.1 What are type hints?

Type hints are optional annotations used to indicate the expected data
types of variables, function parameters, and return values.

They help developers understand what type of data a program expects.

Python is dynamically typed, meaning we do not need to specify types
explicitly. However, type hints allow us to communicate intended types
clearly.

Without type hints:

``` python
def add(a, b):
    return a + b
```

A developer may not immediately know whether `a` and `b` should be
integers, floats, or strings, or what the function is expected to
return.

With type hints:

``` python
def add(a: int, b: int) -> int:
    return a + b
```

-   `a: int` indicates that `a` is expected to be an integer.
-   `b: int` indicates that `b` is expected to be an integer.
-   `-> int` indicates that the function is expected to return an
    integer.

## 11.2 Why are type hints important?

1.  **Readability:** Other developers can understand the expected data
    types.
2.  **Maintainability:** Large applications become easier to maintain.
3.  **Error detection:** Static analysis tools can identify potential
    type-related mistakes.
4.  **IDE support:** Editors can provide better autocomplete and
    suggestions.
5.  **Documentation:** Functions become easier to understand without
    reading their complete implementation.

Important: Python does not automatically enforce type hints at runtime.
They are primarily used by developers, IDEs, and static type checkers
such as mypy and Pyright.

## 11.3 Variable type hints

Syntax:

``` python
variable_name: data_type = value
```

Examples:

``` python
name: str = "Rahul"
age: int = 22
salary: float = 45000.50
is_student: bool = True
```

These annotations communicate the intended types.

Python still allows reassignment to a different type at runtime:

``` python
age: int = 22

age = "Twenty Two"

print(age)
```

This executes normally, even though the reassignment conflicts with the
annotation. A static type checker may report a type error.

## 11.4 Function parameter type hints

``` python
def greet(name: str):
    print("Hello", name)

greet("Rahul")
```

Output:

``` text
Hello Rahul
```

Another example:

``` python
def multiply(a: int, b: int):
    return a * b

print(multiply(10, 20))
```

Output:

``` text
200
```

## 11.5 Return type hints

We can specify the expected return type using the arrow (`->`).

``` python
def add(a: int, b: int) -> int:
    return a + b

result = add(10, 20)

print(result)
```

Output:

``` text
30
```

Another example:

``` python
def get_name() -> str:
    return "Rahul"

print(get_name())
```

Output:

``` text
Rahul
```

`-> int` and `-> str` indicate the expected return types.

## 11.6 Type hints with different data types

``` python
name: str = "Rahul"
age: int = 22
percentage: float = 85.5
is_passed: bool = True

def display_student(name: str, age: int) -> None:
    print("Name:", name)
    print("Age:", age)

display_student(name, age)
```

Output:

``` text
Name: Rahul
Age: 22
```

The `-> None` annotation indicates that the function is not expected to
return a meaningful value.

## 11.7 Type hints with collections

Type hints can specify the expected types of elements inside
collections.

List:

``` python
marks: list[int] = [80, 85, 90, 95]
```

Other examples:

``` python
names: list[str] = ["Rahul", "Ravi", "Priya"]

coordinates: tuple[int, int] = (10, 20)

unique_numbers: set[int] = {1, 2, 3}

student: dict[str, int] = {
    "Rahul": 85,
    "Ravi": 90
}
```

These built-in generic annotations are supported in modern Python
versions.

## 11.8 Type hints with multiple possible types

Sometimes a variable can accept more than one data type. For example, an
employee's salary may be represented as either an integer or a float.

Using `Union`:

``` python
from typing import Union

salary: Union[int, float] = 45000

salary = 45000.50
```

Using the modern union operator:

``` python
salary: int | float = 45000

salary = 45000.50
```

The `|` syntax for type unions is supported from Python 3.10.

## 11.9 Optional type hints

Sometimes a variable may contain a value or `None`.

Using `Optional`:

``` python
from typing import Optional

phone: Optional[str] = "9876543210"

phone = None
```

Equivalent modern syntax:

``` python
phone: str | None = "9876543210"

phone = None
```

## 11.10 Type hints with dictionaries and lists in functions

``` python
def calculate_average(marks: list[int]) -> float:
    total = sum(marks)
    average = total / len(marks)
    return average

result = calculate_average([80, 90, 85, 95])

print(result)
```

Output:

``` text
87.5
```

The function communicates that it expects a list of integers and returns
a float.

## 11.11 Type hints with custom classes

``` python
class Student:
    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age

def display_student(student: Student) -> None:
    print(student.name)
    print(student.age)

s1 = Student("Rahul", 22)

display_student(s1)
```

Output:

``` text
Rahul
22
```

`student: Student` indicates that the function expects a `Student`
object.

## 11.13 Type checking using mypy

Mypy is a static type checker for Python.

Install it:

``` bash
pip install mypy
```

Create `example.py`:

``` python
def add(a: int, b: int) -> int:
    return a + b

result = add(10, 20)

print(result)
```

Run:

``` bash
mypy example.py
```

Mypy checks whether the code is consistent with its type annotations.

Now consider:

``` python
def add(a: int, b: int) -> int:
    return a + b

result = add("10", 20)
```

A static type checker can identify that a string is being passed where
an integer is expected.

This helps catch potential mistakes before running the application.

## 11.14 Practical example: Student management program using type hints

``` python
def calculate_total(marks: list[int]) -> int:
    return sum(marks)


def calculate_average(marks: list[int]) -> float:
    return sum(marks) / len(marks)


def check_result(average: float) -> str:
    if average >= 40:
        return "Pass"

    return "Fail"


student_name: str = "Rahul"
student_marks: list[int] = [80, 75, 90, 85]

total: int = calculate_total(student_marks)
average: float = calculate_average(student_marks)
result: str = check_result(average)

print("Student:", student_name)
print("Total Marks:", total)
print("Average:", average)
print("Result:", result)
```

Output:

``` text
Student: Rahul
Total Marks: 330
Average: 82.5
Result: Pass
```

This example demonstrates how type hints improve the readability and
maintainability of a program.

# 13. Practical Exercises for Students

These exercises are arranged from beginner to intermediate and advanced
levels. They can be assigned as classroom practice after teaching the
concepts.

## Beginner

1.  Write a Python program to print your name, age, and college name.
2.  Create variables of type `int`, `float`, `str`, and `bool`. Print
    their values and types.
3.  Take two numbers as input and perform addition, subtraction,
    multiplication, and division.
4.  Write a program to convert an integer into a string and a float.
5.  Create a string containing your name and print its first and last
    characters.

## Intermediate

1.  Create a list of five student names. Add, update, and remove
    elements.
2.  Create a dictionary containing student name, roll number, and marks.
    Display each value.
3.  Create a list containing duplicate values and remove duplicates
    using a set.
4.  Demonstrate the difference between mutable and immutable objects
    using a list and string.
5.  Create two variables referring to the same list and demonstrate how
    modifying one affects the other.
6.  Write a program that uses `try-except` to handle invalid integer
    input.

## Advanced

1.  Create a `Student` class and inspect its object using `type()`,
    `id()`, `dir()`, and `vars()`.
2.  Write a function with type hints that accepts a list of integers and
    returns the maximum value.
3.  Create a nested list and demonstrate the difference between shallow
    copy and deep copy.
4.  Write a student marks management program using dictionaries, lists,
    and type hints.
5.  Create a function that accepts an integer or float and returns its
    square using `Union` or the `|` operator.

# 14. Important Interview Questions and Answers

### 1. Is Python compiled or interpreted?

Python is commonly described as an interpreted language. In CPython,
source code is first compiled into bytecode, which is then executed by
the Python virtual machine.

### 2. What is the difference between a list and a tuple?

A list is mutable, whereas a tuple is immutable. Lists use square
brackets, and tuples generally use parentheses.

### 3. What is dynamic typing?

Dynamic typing means that variables do not require explicit type
declarations, and their names can refer to objects of different types
during execution.

### 4. What is the difference between `==` and `is`?

`==` compares values, whereas `is` compares object identity.

### 5. What is the difference between comments and docstrings?

Comments explain code using `#`. Docstrings document modules, functions,
and classes using string literals.

### 6. Why is indentation important in Python?

Indentation defines code blocks and determines which statements belong
to conditional statements, loops, functions, and classes.

### 7. What is the difference between mutable and immutable objects?

Mutable objects can be changed after creation, whereas immutable objects
cannot be changed after creation.

### 8. What does `input()` return?

The `input()` function returns a string by default, even if the user
enters a number.

### 9. What is the difference between `type()` and `isinstance()`?

`type()` identifies an object's exact type, whereas `isinstance()` also
considers inheritance relationships.

### 10. Are type hints enforced in Python?

No. Python does not enforce type hints automatically at runtime. Static
type checkers such as mypy can analyze them.

### 11. What is `None` in Python?

`None` represents the absence of a value and belongs to the `NoneType`
class.

### 12. What is a virtual environment?

A virtual environment is an isolated Python environment that allows
different projects to maintain their own dependencies.
