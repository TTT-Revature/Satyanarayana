## 3. Escape Characters and Multiline Strings

### 3.1 Escape Characters

#### What are Escape Characters?
Escape characters are special characters used inside strings to represent formatting or characters that cannot easily be typed directly.

In Python, escape sequences begin with a backslash (`\`).

#### Common Escape Sequences

| Escape sequence | Meaning | Example |
| :--- | :--- | :--- |
| `\n` | New line | `"Hello\nWorld"` |
| `\t` | Horizontal tab | `"Hello\tWorld"` |
| `\\` | Backslash | `"C:\\Python"` |
| `\'` | Single quote | `'It\'s Python'` |
| `\"` | Double quote | `"He said \"Hello\""` |
| `\r` | Carriage return | `"Hello\rWorld"` |
| `\b` | Backspace | `"Hello\b"` |
| `\f` | Form feed | `"Hello\fWorld"` |
| `\v` | Vertical tab | `"Hello\vWorld"` |
| `\0` | Null character | `"Hello\0World"` |

#### Example 1: New Line
```python
print("Hello\nWorld")
```

**Output:**
```text
Hello
World
```

#### Example 2: Tab Space
```python
print("Name\tAge\tCity")
print("Rahul\t22\tHyderabad")
```

**Output:**
```text
Name    Age     City
Rahul   22      Hyderabad
```

#### Example 3: Backslash
```python
path = "C:\\Users\\Python\\Documents"

print(path)
```

**Output:**
```text
C:\Users\Python\Documents
```

#### Example 4: Quotation Marks
```python
print("He said, \"Python is easy.\"")
```

**Output:**
```text
He said, "Python is easy."
```

### 3.2 Multiline Strings

A multiline string is a string that contains multiple lines of text. Python allows multiline strings using triple single quotes or triple double quotes.

#### Example 1: Triple Double Quotes
```python
message = """Welcome to Python Programming.
Python is easy to learn.
Python is widely used in AI and Data Science."""

print(message)
```

**Output:**
```text
Welcome to Python Programming.
Python is easy to learn.
Python is widely used in AI and Data Science.
```

#### Example 2: Triple Single Quotes
```python
message = '''Python supports
multiple lines
inside a string.'''

print(message)
```

#### Example 3: Multiline Strings for Documentation
Triple-quoted strings are also commonly used for docstrings, which describe the purpose of a function, class, or module.

```python
def add(a, b):
    """
    This function accepts two numbers
    and returns their sum.
    """
    return a + b

print(add(10, 20))
```

**Output:**
```text
30
```

---

### 3.3 Raw Strings

A raw string tells Python not to interpret most backslash escape sequences. Raw strings are particularly useful when working with Windows file paths and regular expressions.

**Syntax:**
```python
r"string"
```

**Example:**
```python
path = r"C:\Users\Python\Documents"

print(path)
```

**Output:**
```text
C:\Users\Python\Documents
```

**Compare:**
```python
print("Hello\nWorld")
print(r"Hello\nWorld")
```

**Output:**
```text
Hello
World
Hello\nWorld
```
The raw string preserves the backslash and the letter `n` instead of creating a new line.

## 4. String Formatting

### 4.1 What is String Formatting?
String formatting is the process of inserting variables or expressions into a string. It allows us to create dynamic messages without manually joining multiple strings.

Python provides three commonly used approaches:
* Using the `%` operator.
* Using the `format()` method.
* Using f-strings.

#### A. Formatting Using the `%` Operator
This is an older approach to string formatting.

**Common format specifiers:**

| Specifier | Meaning |
| :--- | :--- |
| `%s` | String |
| `%d` | Integer |
| `%f` | Floating-point number |
| `%.2f` | Floating-point number with 2 decimal places |
| `%c` | Character |
| `%x` | Hexadecimal integer |

**Example:**
```python
name = "Rahul"
age = 22
percentage = 89.567

print("Name: %s" % name)
print("Age: %d" % age)
print("Percentage: %.2f" % percentage)
```

**Output:**
```text
Name: Rahul
Age: 22
Percentage: 89.57
```

**Multiple values:**
```python
name = "Rahul"
age = 22

print("My name is %s and I am %d years old." % (name, age))
```

**Output:**
```text
My name is Rahul and I am 22 years old.
```

#### B. Using the `format()` Method
The `format()` method inserts values into placeholders `{}`.

**Syntax:**
```python
"string {}".format(value)
```

**Example:**
```python
name = "Rahul"
age = 22

message = "My name is {} and I am {} years old.".format(name, age)

print(message)
```

**Output:**
```text
My name is Rahul and I am 22 years old.
```

**Using Positional Arguments:**
```python
message = "I like {} and {}".format("Python", "Java")

print(message)
```

**Output:**
```text
I like Python and Java
```

We can also specify positions:
```python
message = "I like {1} and {0}".format("Python", "Java")

print(message)
```

**Output:**
```text
I like Java and Python
```

**Using Named Arguments:**
```python
message = "Name: {name}, Age: {age}".format(
    name="Rahul",
    age=22
)

print(message)
```

**Output:**
```text
Name: Rahul, Age: 22
```

**Formatting Decimal Values:**
```python
price = 125.5678

print("Price: {:.2f}".format(price))
```

**Output:**
```text
Price: 125.57
```

#### C. Using f-Strings

##### What are f-Strings?
Formatted string literals, commonly called f-strings, allow us to insert variables and expressions directly inside strings. They were introduced in Python 3.6.

**Syntax:**
```python
f"Text {variable}"
```

**Example:**
```python
name = "Rahul"
age = 22

print(f"My name is {name} and I am {age} years old.")
```

**Output:**
```text
My name is Rahul and I am 22 years old.
```

**Example 2: Performing calculations**
```python
a = 10
b = 20

print(f"Sum = {a + b}")
print(f"Product = {a * b}")
```

**Output:**
```text
Sum = 30
Product = 200
```

**Example 3: Decimal formatting**
```python
price = 1234.56789

print(f"Price: {price:.2f}")
```

**Output:**
```text
Price: 1234.57
```

**Example 4: Percentage formatting**
```python
percentage = 0.8567

print(f"Percentage: {percentage:.2%}")
```

**Output:**
```text
Percentage: 85.67%
```

**Example 5: Thousands separator**
```python
salary = 1500000

print(f"Salary: {salary:,}")
```

**Output:**
```text
Salary: 1,500,000
```

**Example 6: Date and time formatting**
```python
from datetime import datetime

today = datetime.now()

print(f"Date: {today:%d-%m-%Y}")
```

#### Comparison of String Formatting Methods

| Feature | `%` operator | `format()` | f-string |
| :--- | :--- | :--- | :--- |
| Readability | Moderate | Good | Very good |
| Variable insertion | Yes | Yes | Yes |
| Expressions | Limited | Limited | Yes |
| Decimal formatting | Yes | Yes | Yes |
| Modern usage | Legacy | Supported | Recommended |

> **Teacher's note:** In modern Python development, f-strings are generally preferred because they are readable, concise, and support expressions directly.

## 5. Introduction to Regular Expressions

### 5.1 What is a Regular Expression?
A Regular Expression (Regex) is a sequence of characters that defines a search pattern. It is used to identify, search, extract, validate, or replace specific patterns in text.

Python provides a built-in module called `re` to work with regular expressions.

#### Why do we need Regular Expressions?
Consider a situation where we have the following text:
```text
Contact us at support@gmail.com
or admin@yahoo.com
```
Suppose we want to extract all email addresses. Without regular expressions, we would need to write multiple conditions and manually check each character. With regular expressions, we can define a pattern that identifies email-like text.

#### Importing the `re` Module
```python
import re
```

#### Basic Example
```python
import re

text = "Python is a programming language"

result = re.search("Python", text)

if result:
    print("Pattern found")
else:
    print("Pattern not found")
```

**Output:**
```text
Pattern found
```

#### Applications of Regular Expressions
* Email validation.
* Phone number validation.
* Password validation.
* Extracting dates from documents.
* Searching for specific words.
* Extracting information from text files.
* Cleaning and preprocessing datasets.
* Extracting structured information from unstructured text.

Regular expressions are particularly useful in Data Science, Natural Language Processing, web development, and data cleaning.
