## 8. Python Regular Expression Functions

Python's `re` module provides several functions for working with regular expressions.

The most important functions are:

| Function | Purpose |
| :--- | :--- |
| `re.match()` | Checks for a match at the beginning of a string |
| `re.search()` | Searches for the first match anywhere |
| `re.fullmatch()` | Checks whether the entire string matches |
| `re.findall()` | Returns all non-overlapping matches |
| `re.finditer()` | Returns an iterator of match objects |
| `re.sub()` | Replaces matching patterns |
| `re.split()` | Splits a string using a regex pattern |

Let's understand each function.

### 8.1 `re.search()`

#### What is `re.search()`?
The `re.search()` function searches the entire string and returns the first matching occurrence. If a match is found, it returns a Match object. Otherwise, it returns `None`.

**Syntax:**
```python
re.search(pattern, string)
```

#### Example:
```python
import re

text = "Python is easy to learn"

result = re.search("easy", text)

if result:
    print("Pattern found")
    print("Matched text:", result.group())
    print("Starting position:", result.start())
    print("Ending position:", result.end())
else:
    print("Pattern not found")
```

**Output:**
```text
Pattern found
Matched text: easy
Starting position: 10
Ending position: 14
```
The ending position is exclusive.

#### Important Methods of Match Objects

| Method | Description |
| :--- | :--- |
| `group()` | Returns matched text |
| `start()` | Returns starting index |
| `end()` | Returns ending index |
| `span()` | Returns start and end positions |

**Example:**
```python
import re

text = "Hello Python"

result = re.search("Python", text)

print(result.group())
print(result.start())
print(result.end())
print(result.span())
```

**Output:**
```text
Python
6
12
(6, 12)
```

### 8.2 `re.match()`

#### What is `re.match()`?
The `re.match()` function checks whether the pattern matches at the beginning of the string. It does not search through the entire string for a match.

**Syntax:**
```python
re.match(pattern, string)
```

#### Example:
```python
import re

text = "Python is easy"

result = re.match("Python", text)

if result:
    print("Match found")
else:
    print("No match")
```

**Output:**
```text
Match found
```

Now consider:
```python
import re

text = "I love Python"

result = re.match("Python", text)

if result:
    print("Match found")
else:
    print("No match")
```

**Output:**
```text
No match
```
Why? Because `Python` is not at the beginning of the string.

---

### 8.3 `re.fullmatch()`

#### What is `re.fullmatch()`?
The `re.fullmatch()` function checks whether the entire string matches the specified pattern. Even one extra character can cause the match to fail.

**Syntax:**
```python
re.fullmatch(pattern, string)
```

#### Example:
```python
import re

text = "12345"

result = re.fullmatch(r"\d+", text)

if result:
    print("Valid input")
else:
    print("Invalid input")
```

**Output:**
```text
Valid input
```

Now consider:
```python
import re

text = "12345abc"

result = re.fullmatch(r"\d+", text)

if result:
    print("Valid input")
else:
    print("Invalid input")
```

**Output:**
```text
Invalid input
```
Because the entire string must contain only digits as required by the pattern.

#### Difference Between `search()`, `match()`, and `fullmatch()`

Consider:
```python
import re

text = "Python123"

print(re.search(r"\d+", text))
print(re.match(r"\d+", text))
print(re.fullmatch(r"\d+", text))
```

**Output:**
```text
<re.Match object ...>
None
None
```

**Visual Comparison on `"Python123"`:**
* **`search()` — anywhere:** Scans `P y t h o n` $\rightarrow$ finds **`1 2 3`** at the end.
* **`match()` — beginning only:** Checks `P` at index 0 $\rightarrow$ fails because digits are not at the beginning.
* **`fullmatch()` — entire string:** Checks `P y t h o n 1 2 3` $\rightarrow$ fails because the entire string is not digits.

| Feature | `search()` | `match()` | `fullmatch()` |
| :--- | :--- | :--- | :--- |
| Searches anywhere | Yes | No | No |
| Checks beginning | Not restricted | Yes | Yes |
| Checks entire string | No | No | Yes |
| Returns Match object | If matched | If matched | If matched |

> **Remember:** Use `fullmatch()` when validating an entire input, such as a mobile number or password.

### 8.4 `re.findall()`

#### What is `re.findall()`?
The `re.findall()` function returns all non-overlapping matches of a pattern in a string. It returns the matches as a list.

**Syntax:**
```python
re.findall(pattern, string)
```

#### Example 1: Extracting all digits
```python
import re

text = "My marks are 85, 90 and 95"

result = re.findall(r"\d+", text)

print(result)
```

**Output:**
```text
['85', '90', '95']
```

#### Example 2: Extracting all words
```python
import re

text = "Python is easy to learn"

result = re.findall(r"\w+", text)

print(result)
```

**Output:**
```text
['Python', 'is', 'easy', 'to', 'learn']
```

#### Example 3: Extracting uppercase letters
```python
import re

text = "PyTHon PROgramming"

result = re.findall(r"[A-Z]", text)

print(result)
```

**Output:**
```text
['P', 'T', 'H', 'P', 'R', 'O']
```

#### Example 4: Extracting numbers from a sentence
```python
import re

text = "I have 2 laptops, 3 phones and 10 books"

numbers = re.findall(r"\d+", text)

print(numbers)
```

**Output:**
```text
['2', '3', '10']
```

#### Example 5: Using Groups with `findall()`
```python
import re

text = "Rahul scored 85 and Ravi scored 90"

pattern = r"(\w+) scored (\d+)"

result = re.findall(pattern, text)

print(result)
```

**Output:**
```text
[('Rahul', '85'), ('Ravi', '90')]
```
When the pattern contains capturing groups, `findall()` returns the captured groups rather than the entire matched text.

### 8.5 `re.sub()`

#### What is `re.sub()`?
The `re.sub()` function replaces occurrences of a pattern with another string. It is commonly used for text cleaning and data preprocessing.

**Syntax:**
```python
re.sub(pattern, replacement, string, count=0)
```

**Parameters:**
* `pattern`: Pattern to search for.
* `replacement`: Text that replaces the matched pattern.
* `string`: Original text.
* `count`: Maximum number of replacements. Default is 0, meaning replace all occurrences.

#### Example 1: Replacing digits
```python
import re

text = "Python123Programming456"

result = re.sub(r"\d", "*", text)

print(result)
```

**Output:**
```text
Python***Programming***
```

#### Example 2: Removing all digits
```python
import re

text = "My phone number is 9876543210"

result = re.sub(r"\d", "", text)

print(result)
```

**Output:**
```text
My phone number is 
```

#### Example 3: Replacing multiple spaces
```python
import re

text = "Python     is    easy"

result = re.sub(r"\s+", " ", text)

print(result)
```

**Output:**
```text
Python is easy
```
Here, `\s+` matches one or more whitespace characters.

#### Example 4: Using count
```python
import re

text = "apple apple apple"

result = re.sub("apple", "orange", text, count=2)

print(result)
```

**Output:**
```text
orange orange apple
```
Only the first two occurrences are replaced.

#### Example 5: Removing Special Characters
```python
import re

text = "Hello@Python#Programming!"

result = re.sub(r"[^a-zA-Z0-9 ]", "", text)

print(result)
```

**Output:**
```text
HelloPythonProgramming
```

**Explanation:** `[^a-zA-Z0-9 ]` matches any character that is not an uppercase letter, lowercase letter, digit, or space.
