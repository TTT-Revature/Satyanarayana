### 1.2 String Indexing and Slicing

#### What is Indexing?
Indexing is the process of accessing an individual character from a string using its position.

Python supports two types of indexing:
* Positive indexing
* Negative indexing

Consider the following string:
```python
word = "PYTHON"
```

| Character | P | Y | T | H | O | N |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Positive Index** | 0 | 1 | 2 | 3 | 4 | 5 |
| **Negative Index** | -6 | -5 | -4 | -3 | -2 | -1 |

#### A. Positive Indexing
Positive indexing starts from zero and moves from left to right.

```python
word = "PYTHON"

print(word[0])
print(word[1])
print(word[2])
print(word[5])
```

**Output:**
```text
P
Y
T
N
```

#### B. Negative Indexing
Negative indexing starts from -1 and moves from right to left.

```python
word = "PYTHON"

print(word[-1])
print(word[-2])
print(word[-3])
```

**Output:**
```text
N
O
H
```

#### C. What happens if we access an invalid index?
```python
word = "PYTHON"

print(word[10])
```

**Output:**
```text
IndexError: string index out of range
```
This error occurs because the string does not contain an element at index 10.

#### What is String Slicing?
Slicing is the process of extracting a portion of a string.

**Syntax:**
```python
string[start:end:step]
```

| Parameter | Description |
| :--- | :--- |
| `start` | Starting index (included) |
| `end` | Ending index (excluded) |
| `step` | Number of positions to move |

#### Example 1: Basic slicing
```python
word = "PYTHON"

print(word[0:3])
print(word[1:4])
print(word[2:6])
```

**Output:**
```text
PYT
YTH
THON
```
Notice that the ending index is not included.

#### Example 2: Omitting start and end
```python
word = "PYTHON"

print(word[:3])
print(word[3:])
print(word[:])
```

**Output:**
```text
PYT
HON
PYTHON
```
* `word[:3]` starts from the beginning.
* `word[3:]` continues until the end.
* `word[:]` returns the complete string.

#### Example 3: Using negative slicing
```python
word = "PYTHON"

print(word[-4:])
print(word[:-2])
```

**Output:**
```text
THON
PYTH
```

#### Example 4: Using step
```python
word = "PYTHON"

print(word[::1])
print(word[::2])
print(word[::-1])
```

**Output:**
```text
PYTHON
PTO
NOHTYP
```
Here:
* `1` means move one position forward.
* `2` means skip every alternate character.
* `-1` means move backward, reversing the string.

#### Practical Example: Reverse a String
```python
text = input("Enter a string: ")

reverse = text[::-1]

print("Reversed string:", reverse)
```

**Input:**
```text
Python
```

**Output:**
```text
Reversed string: nohtyP
```

**Important points:**
* Indexing returns a single character.
* Slicing returns a substring.
* Positive indexing starts at 0.
* Negative indexing starts at -1.
* The ending index in slicing is excluded.
* Strings are immutable.
