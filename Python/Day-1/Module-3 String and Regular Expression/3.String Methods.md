### 1.3 String Methods

Python provides several built-in string methods to perform operations such as changing letter cases, searching, checking characters, and modifying text.

String methods do not modify the original string because strings are immutable. Instead, they return a new string or another result.

Consider:
```python
text = "Hello Python"
```

#### A. Case Conversion Methods

| Method | Description |
| :--- | :--- |
| `upper()` | Converts all characters to uppercase |
| `lower()` | Converts all characters to lowercase |
| `capitalize()` | Capitalizes the first character |
| `title()` | Capitalizes the first character of each word |
| `swapcase()` | Changes uppercase to lowercase and vice versa |
| `casefold()` | Performs aggressive lowercase conversion for case-insensitive comparisons |

**Example:**
```python
text = "hello PYTHON programming"

print(text.upper())
print(text.lower())
print(text.capitalize())
print(text.title())
print(text.swapcase())
```

**Output:**
```text
HELLO PYTHON PROGRAMMING
hello python programming
Hello python programming
Hello Python Programming
HELLO python PROGRAMMING
```

#### B. Searching Methods

| Method | Description |
| :--- | :--- |
| `find()` | Returns the first matching index or -1 |
| `index()` | Returns the first matching index or raises ValueError |
| `count()` | Counts occurrences of a substring |
| `startswith()` | Checks whether a string starts with a given value |
| `endswith()` | Checks whether a string ends with a given value |

**Example:**
```python
text = "Python is easy and Python is powerful"

print(text.find("Python"))
print(text.index("easy"))
print(text.count("Python"))
print(text.startswith("Python"))
print(text.endswith("powerful"))
```

**Output:**
```text
0
10
2
True
True
```

**Difference between `find()` and `index()`:**
```python
text = "Python"

print(text.find("Java"))
```

**Output:**
```text
-1
```

But:
```python
text = "Python"

print(text.index("Java"))
```

**Output:**
```text
ValueError: substring not found
```

#### C. Character Checking Methods
These methods return either `True` or `False`.

| Method | Description |
| :--- | :--- |
| `isalpha()` | Checks whether all characters are letters |
| `isdigit()` | Checks whether all characters are digits |
| `isalnum()` | Checks whether all characters are letters or digits |
| `isspace()` | Checks whether all characters are whitespace |
| `islower()` | Checks whether all cased characters are lowercase |
| `isupper()` | Checks whether all cased characters are uppercase |
| `istitle()` | Checks whether the string follows title case |
| `isdecimal()` | Checks whether all characters are decimal digits |
| `isnumeric()` | Checks whether all characters are numeric |

**Example:**
```python
print("Python".isalpha())
print("12345".isdigit())
print("Python123".isalnum())
print("Hello World".isspace())
print("hello".islower())
print("HELLO".isupper())
```

**Output:**
```text
True
True
True
False
True
True
```

**Important distinction:**
* `isdecimal()` accepts decimal digits.
* `isdigit()` accepts decimal digits and some additional digit characters.
* `isnumeric()` accepts an even wider range of numeric characters, including some fractions and numeric symbols.

#### D. Alignment Methods
These methods help arrange strings within a specified width.

| Method | Description |
| :--- | :--- |
| `center()` | Places text in the center |
| `ljust()` | Aligns text to the left |
| `rjust()` | Aligns text to the right |
| `zfill()` | Adds zeros to the beginning |

**Example:**
```python
text = "Python"

print(text.center(12, "*"))
print(text.ljust(10, "-"))
print(text.rjust(10, "-"))
print("25".zfill(5))
```

**Output:**
```text
***Python***
Python----
----Python
00025
```

#### E. Other Useful Methods
```python
text = "Python programming"

# Length
print(len(text))

# Replace
print(text.replace("Python", "Java"))

# Remove leading and trailing whitespace
print("  Hello  ".strip())

# Split into words
print(text.split())

# Check whether the string contains a substring
print("Python" in text)
```

**Output:**
```text
18
Java programming
Hello
['Python', 'programming']
True
```
