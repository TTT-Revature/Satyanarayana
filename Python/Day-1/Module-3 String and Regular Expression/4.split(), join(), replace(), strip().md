## 2. Important String Operations

### 2.1 `split()` Method

#### What is `split()`?
The `split()` method divides a string into multiple parts based on a specified separator. It returns the result as a list.

**Syntax:**
```python
string.split(separator, maxsplit)
```

**Parameters:**
* `separator`: Character or string used to divide the text.
* `maxsplit`: Maximum number of splits allowed.

#### Example 1: Splitting by spaces
```python
text = "Python is easy to learn"

result = text.split()

print(result)
```

**Output:**
```text
['Python', 'is', 'easy', 'to', 'learn']
```
If no separator is provided, Python splits using whitespace and handles consecutive whitespace together.

#### Example 2: Splitting by comma
```python
data = "Java,Python,C,JavaScript"

languages = data.split(",")

print(languages)
```

**Output:**
```text
['Java', 'Python', 'C', 'JavaScript']
```

#### Example 3: Using `maxsplit`
```python
text = "Python is easy to learn"

result = text.split(" ", 2)

print(result)
```

**Output:**
```text
['Python', 'is', 'easy to learn']
```
Only two splits are performed.

#### Practical Example: Processing Student Data
```python
data = "101,Rahul,85"

student = data.split(",")

roll_no = student[0]
name = student[1]
marks = student[2]

print("Roll Number:", roll_no)
print("Name:", name)
print("Marks:", marks)
```

**Output:**
```text
Roll Number: 101
Name: Rahul
Marks: 85
```

### 2.2 `join()` Method

#### What is `join()`?
The `join()` method combines multiple strings into a single string using a specified separator. It is essentially the opposite of `split()`.

**Syntax:**
```python
separator.join(iterable)
```
Here, an iterable can be a list or tuple containing strings.

#### Example 1: Joining words
```python
words = ["Python", "is", "easy"]

result = " ".join(words)

print(result)
```

**Output:**
```text
Python is easy
```

#### Example 2: Joining using a comma
```python
languages = ["Python", "Java", "C++"]

result = ", ".join(languages)

print(result)
```

**Output:**
```text
Python, Java, C++
```

#### Example 3: Joining using a hyphen
```python
date = ["16", "11", "2026"]

result = "-".join(date)

print(result)
```

**Output:**
```text
16-11-2026
```

#### Practical Example: Converting a List into a Sentence
```python
words = ["Learning", "Python", "is", "interesting"]

sentence = " ".join(words)

print(sentence)
```

**Output:**
```text
Learning Python is interesting
```

**Important:** All elements passed to `join()` must be strings.

**Incorrect:**
```python
numbers = [10, 20, 30]

print(",".join(numbers))
```
This produces a `TypeError`.

**Correct:**
```python
numbers = [10, 20, 30]

result = ",".join(map(str, numbers))

print(result)
```

**Output:**
```text
10,20,30
```

### 2.3 `replace()` Method

#### What is `replace()`?
The `replace()` method replaces an existing substring with another substring.

**Syntax:**
```python
string.replace(old, new, count)
```

**Parameters:**
* `old`: Existing substring.
* `new`: Replacement substring.
* `count`: Maximum number of replacements.

#### Example 1: Basic replacement
```python
text = "I like Java"

result = text.replace("Java", "Python")

print(result)
```

**Output:**
```text
I like Python
```

#### Example 2: Replacing multiple occurrences
```python
text = "apple apple apple"

result = text.replace("apple", "orange")

print(result)
```

**Output:**
```text
orange orange orange
```

#### Example 3: Using count
```python
text = "apple apple apple"

result = text.replace("apple", "orange", 2)

print(result)
```

**Output:**
```text
orange orange apple
```
Only the first two occurrences are replaced.

#### Practical Example: Removing Spaces
```python
text = "Python Programming"

result = text.replace(" ", "")

print(result)
```

**Output:**
```text
PythonProgramming
```

### 2.4 `strip()` Method

#### What is `strip()`?
The `strip()` method removes unwanted characters from the beginning and end of a string.

Python provides three related methods:

| Method | Description |
| :--- | :--- |
| `strip()` | Removes characters from both ends |
| `lstrip()` | Removes characters from the left side |
| `rstrip()` | Removes characters from the right side |

#### Example 1: Using `strip()`
```python
text = "   Hello Python   "

print(text.strip())
```

**Output:**
```text
Hello Python
```

#### Example 2: Using `lstrip()`
```python
text = "   Hello Python   "

print(text.lstrip())
```

**Output:**
```text
Hello Python   
```

#### Example 3: Using `rstrip()`
```python
text = "   Hello Python   "

print(text.rstrip())
```

**Output:**
```text
   Hello Python
```

#### Example 4: Removing specific characters
```python
text = "***Python***"

print(text.strip("*"))
```

**Output:**
```text
Python
```

**Important:** The argument to `strip()` is treated as a set of characters, not as an exact substring.

**Example:**
```python
text = "xyPythonxy"

print(text.strip("xy"))
```

**Output:**
```text
Python
```

#### Practical Example: Cleaning User Input
```python
name = input("Enter your name: ")

name = name.strip()

print("Welcome,", name)
```

If the user enters:
```text
    Rahul    
```

**Output:**
```text
Welcome, Rahul
```
This is particularly useful when processing user input, CSV data, and text files.
