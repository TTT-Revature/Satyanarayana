## 5. Introduction to Regular Expressions

### 5.1 What is a Regular Expression?
A Regular Expression (Regex) is a sequence of characters that defines a search pattern. It is used to identify, search, extract, validate, or replace specific patterns in text.

Python provides a built-in module called `re` to work with regular expressions.

#### Why do we need Regular Expressions?
Consider a situation where we have the following text:
```text
Contact us at support@gmail.com
or admin@yahoo.com
```
Suppose we want to extract all email addresses. Without regular expressions, we would need to write multiple conditions and manually check each character. With regular expressions, we can define a pattern that identifies email-like text.

#### Importing the `re` Module
```python
import re
```

#### Basic Example
```python
import re

text = "Python is a programming language"

result = re.search("Python", text)

if result:
    print("Pattern found")
else:
    print("Pattern not found")
```

**Output:**
```text
Pattern found
```

#### Applications of Regular Expressions
* Email validation.
* Phone number validation.
* Password validation.
* Extracting dates from documents.
* Searching for specific words.
* Extracting information from text files.
* Cleaning and preprocessing datasets.
* Extracting structured information from unstructured text.

Regular expressions are particularly useful in Data Science, Natural Language Processing, web development, and data cleaning.
