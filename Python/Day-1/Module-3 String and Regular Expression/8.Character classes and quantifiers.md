## 6. Character Classes and Quantifiers

Regular expressions use special symbols to describe patterns. Two important concepts are:
* **Character classes:** Define which characters are allowed.
* **Quantifiers:** Define how many times a character or group can occur.

### 6.1 Character Classes
Character classes specify the set of characters that can match at a particular position.

#### Common Character Classes

| Pattern | Meaning |
| :--- | :--- |
| `[abc]` | Matches a, b, or c |
| `[a-z]` | Matches lowercase letters |
| `[A-Z]` | Matches uppercase letters |
| `[0-9]` | Matches digits from 0 to 9 |
| `[a-zA-Z]` | Matches uppercase or lowercase letters |
| `[a-zA-Z0-9]` | Matches letters and digits |
| `[^abc]` | Matches any character except a, b, or c |
| `[^0-9]` | Matches any non-digit character |

#### Example 1: Matching lowercase letters
```python
import re

text = "Hello Python 123"

result = re.findall("[a-z]", text)

print(result)
```

**Output:**
```text
['e', 'l', 'l', 'o', 'y', 't', 'h', 'o', 'n']
```

#### Example 2: Extracting digits
```python
import re

text = "My age is 22 and my roll number is 101"

result = re.findall("[0-9]", text)

print(result)
```

**Output:**
```text
['2', '2', '1', '0', '1']
```
Notice that each digit is returned individually.

To extract complete numbers, use a quantifier:
```python
result = re.findall("[0-9]+", text)

print(result)
```

**Output:**
```text
['22', '101']
```

### 6.2 Special Character Classes
Python regex supports predefined character classes.

| Pattern | Meaning |
| :--- | :--- |
| `\d` | Any digit |
| `\D` | Any non-digit |
| `\w` | Word character: letters, digits, underscore |
| `\W` | Non-word character |
| `\s` | Whitespace character |
| `\S` | Non-whitespace character |
| `.` | Any character except newline by default |

**Example:**
```python
import re

text = "Python 123 Programming"

print(re.findall(r"\d", text))
print(re.findall(r"\w+", text))
print(re.findall(r"\s", text))
```

**Output:**
```text
['1', '2', '3']
['Python', '123', 'Programming']
[' ', ' ']
```

**Important:** The `r` prefix is useful when writing regex patterns because it prevents Python from interpreting backslashes as ordinary string escape sequences.

### 6.3 Quantifiers
Quantifiers specify how many times a character, character class, or group should appear.

| Quantifier | Meaning |
| :--- | :--- |
| `*` | Zero or more occurrences |
| `+` | One or more occurrences |
| `?` | Zero or one occurrence |
| `{n}` | Exactly n occurrences |
| `{n,}` | At least n occurrences |
| `{n,m}` | Between n and m occurrences |

#### Example 1: Asterisk (`*`)
Matches zero or more occurrences.
```python
import re

text = "ab aab aaab b"

result = re.findall("a*b", text)

print(result)
```

**Output:**
```text
['ab', 'aab', 'aaab', 'b']
```
Why does it match `b`? Because `*` allows zero occurrences of `a`.

#### Example 2: Plus (`+`)
Matches one or more occurrences.
```python
import re

text = "ab aab aaab b"

result = re.findall("a+b", text)

print(result)
```

**Output:**
```text
['ab', 'aab', 'aaab']
```
It does not match the standalone `b` because at least one `a` is required.

#### Example 3: Question Mark (`?`)
Matches zero or one occurrence.
```python
import re

text = "color colour"

result = re.findall("colou?r", text)

print(result)
```

**Output:**
```text
['color', 'colour']
```
Here, `u` is optional.

#### Example 4: Exact Number of Occurrences
```python
import re

text = "123 1234 12345"

result = re.findall(r"\d{3}", text)

print(result)
```

**Output:**
```text
['123', '123', '123']
```
This matches groups of exactly three digits, including portions of longer digit sequences.

#### Example 5: Minimum Number of Occurrences
```python
import re

text = "12 123 1234"

result = re.findall(r"\d{2,}", text)

print(result)
```

**Output:**
```text
['12', '123', '1234']
```

#### Example 6: Range of Occurrences
```python
import re

text = "1 12 123 1234 12345"

result = re.findall(r"\d{2,4}", text)

print(result)
```

**Output:**
```text
['12', '123', '1234', '1234']
```
The last result is only the first four digits of `12345`.

### 6.4 Greedy and Non-Greedy Quantifiers
By default, quantifiers are greedy. They try to match as much text as possible. A non-greedy quantifier tries to match as little text as possible.

**Example:**
```python
import re

text = "<h1>Hello</h1><h1>Python</h1>"

greedy = re.findall(r"<h1>.*</h1>", text)

non_greedy = re.findall(r"<h1>.*?</h1>", text)

print(greedy)
print(non_greedy)
```

**Output:**
```text
['<h1>Hello</h1><h1>Python</h1>']
['<h1>Hello</h1>', '<h1>Python</h1>']
```
Here:
* `.*` matches as much as possible.
* `.*?` matches as little as possible.
