## 1. Strings in Python

### 1.1 Creating and Working with Strings

#### What is a String?
A string is a sequence of characters enclosed within quotation marks. In Python, strings are used to represent textual information such as names, addresses, messages, email IDs, and other text-based data.

Python supports three ways of defining strings:
* Single quotes (`' '`)
* Double quotes (`" "`)
* Triple quotes (`''' '''` or `""" """`)

#### Example 1: Creating strings
```python
# Using single quotes
name = 'Python'

# Using double quotes
language = "Programming Language"

# Using triple quotes
description = """Python is a high-level,
interpreted programming language."""

print(name)
print(language)
print(description)
```

**Output:**
```text
Python
Programming Language
Python is a high-level,
interpreted programming language.
```

#### Example 2: Strings containing quotation marks
Suppose we want to store a sentence containing quotation marks.

```python
message = "Python is a 'powerful' language"
print(message)
```

**Output:**
```text
Python is a 'powerful' language
```

We can also use single quotes outside and double quotes inside.

```python
message = 'He said, "Python is easy to learn."'
print(message)
```

#### Important Characteristics of Strings

**1. Strings are immutable**
Once a string is created, its individual characters cannot be modified directly.

```python
name = "Python"

# This will produce an error
name[0] = "J"
```

**Output:**
```text
TypeError: 'str' object does not support item assignment
```

However, we can create a new string.

```python
name = "Python"
name = "J" + name[1:]

print(name)
```

**Output:**
```text
Jython
```

**2. Strings are ordered**
Every character has a specific position called an index.

```python
word = "HELLO"
```

**3. Strings support duplicate characters**
```python
word = "banana"
print(word)
```

**Output:**
```text
banana
```

**4. Strings support iteration**
We can access individual characters using loops.

```python
word = "Python"

for character in word:
    print(character)
```

**Output:**
```text
P
y
t
h
o
n
```

**5. Strings support concatenation and repetition**
Concatenation means joining two or more strings using the `+` operator.

```python
first = "Hello"
second = "World"

result = first + " " + second

print(result)
```

**Output:**
```text
Hello World
```

Repetition means repeating a string using the `*` operator.

```python
word = "Python "

print(word * 3)
```

**Output:**
```text
Python Python Python 
```
