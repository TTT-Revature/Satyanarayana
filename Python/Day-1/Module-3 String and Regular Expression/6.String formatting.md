## 4. String Formatting

### 4.1 What is String Formatting?
String formatting is the process of inserting variables or expressions into a string. It allows us to create dynamic messages without manually joining multiple strings.

Python provides three commonly used approaches:
* Using the `%` operator.
* Using the `format()` method.
* Using f-strings.

#### A. Formatting Using the `%` Operator
This is an older approach to string formatting.

**Common format specifiers:**

| Specifier | Meaning |
| :--- | :--- |
| `%s` | String |
| `%d` | Integer |
| `%f` | Floating-point number |
| `%.2f` | Floating-point number with 2 decimal places |
| `%c` | Character |
| `%x` | Hexadecimal integer |

**Example:**
```python
name = "Rahul"
age = 22
percentage = 89.567

print("Name: %s" % name)
print("Age: %d" % age)
print("Percentage: %.2f" % percentage)
```

**Output:**
```text
Name: Rahul
Age: 22
Percentage: 89.57
```

**Multiple values:**
```python
name = "Rahul"
age = 22

print("My name is %s and I am %d years old." % (name, age))
```

**Output:**
```text
My name is Rahul and I am 22 years old.
```

#### B. Using the `format()` Method
The `format()` method inserts values into placeholders `{}`.

**Syntax:**
```python
"string {}".format(value)
```

**Example:**
```python
name = "Rahul"
age = 22

message = "My name is {} and I am {} years old.".format(name, age)

print(message)
```

**Output:**
```text
My name is Rahul and I am 22 years old.
```

**Using Positional Arguments:**
```python
message = "I like {} and {}".format("Python", "Java")

print(message)
```

**Output:**
```text
I like Python and Java
```

We can also specify positions:
```python
message = "I like {1} and {0}".format("Python", "Java")

print(message)
```

**Output:**
```text
I like Java and Python
```

**Using Named Arguments:**
```python
message = "Name: {name}, Age: {age}".format(
    name="Rahul",
    age=22
)

print(message)
```

**Output:**
```text
Name: Rahul, Age: 22
```

**Formatting Decimal Values:**
```python
price = 125.5678

print("Price: {:.2f}".format(price))
```

**Output:**
```text
Price: 125.57
```

#### C. Using f-Strings

##### What are f-Strings?
Formatted string literals, commonly called f-strings, allow us to insert variables and expressions directly inside strings. They were introduced in Python 3.6.

**Syntax:**
```python
f"Text {variable}"
```

**Example:**
```python
name = "Rahul"
age = 22

print(f"My name is {name} and I am {age} years old.")
```

**Output:**
```text
My name is Rahul and I am 22 years old.
```

**Example 2: Performing calculations**
```python
a = 10
b = 20

print(f"Sum = {a + b}")
print(f"Product = {a * b}")
```

**Output:**
```text
Sum = 30
Product = 200
```

**Example 3: Decimal formatting**
```python
price = 1234.56789

print(f"Price: {price:.2f}")
```

**Output:**
```text
Price: 1234.57
```

**Example 4: Percentage formatting**
```python
percentage = 0.8567

print(f"Percentage: {percentage:.2%}")
```

**Output:**
```text
Percentage: 85.67%
```

**Example 5: Thousands separator**
```python
salary = 1500000

print(f"Salary: {salary:,}")
```

**Output:**
```text
Salary: 1,500,000
```

**Example 6: Date and time formatting**
```python
from datetime import datetime

today = datetime.now()

print(f"Date: {today:%d-%m-%Y}")
```

#### Comparison of String Formatting Methods

| Feature | `%` operator | `format()` | f-string |
| :--- | :--- | :--- | :--- |
| Readability | Moderate | Good | Very good |
| Variable insertion | Yes | Yes | Yes |
| Expressions | Limited | Limited | Yes |
| Decimal formatting | Yes | Yes | Yes |
| Modern usage | Legacy | Supported | Recommended |

> **Teacher's note:** In modern Python development, f-strings are generally preferred because they are readable, concise, and support expressions directly.
