## 6. `for` Loops and `range()`

Loops allow us to execute a block of code repeatedly without writing the same statements multiple times.

For example, suppose we want to print numbers from 1 to 5.

Without a loop:

```python
print(1)
print(2)
print(3)
print(4)
print(5)
```

With a loop:

```python
for i in range(1, 6):
    print(i)
```

Output:

```text
1
2
3
4
5
```

The loop reduces repetition and makes programs easier to maintain.

### 6.1 The `for` loop

A `for` loop is used to iterate over a sequence or iterable, such as a list, tuple, string, dictionary, set, or range.

Syntax:

```python
for variable in sequence:
    statements
```

Example:

```python
fruits = ["Apple", "Banana", "Mango"]

for fruit in fruits:
    print(fruit)
```

Output:

```text
Apple
Banana
Mango
```

Explanation:

* Python gets the first element from the list.
* It assigns that element to `fruit`.
* It executes the indented block.
* It moves to the next element.
* It stops when there are no more elements.

### 6.2 The `range()` function

The `range()` function generates a sequence of integers. It is commonly used with `for` loops.

It supports three forms.

#### Form 1: `range(stop)`

Starts at zero and stops before the specified number.

```python
for i in range(5):
    print(i)
```

Output:

```text
0
1
2
3
4
```

`range(5)` generates five values: `0`, `1`, `2`, `3`, and `4`.

#### Form 2: `range(start, stop)`

Starts from the specified starting value and stops before the ending value.

```python
for i in range(1, 6):
    print(i)
```

Output:

```text
1
2
3
4
5
```

The stop value is exclusive. This means `6` is not included.

#### Form 3: `range(start, stop, step)`

The third parameter specifies the increment or decrement.

```python
for i in range(2, 11, 2):
    print(i)
```

Output:

```text
2
4
6
8
10
```

Here, the loop increases the value by `2` each time.

#### Using a negative step

A negative step allows us to generate numbers in descending order.

```python
for i in range(5, 0, -1):
    print(i)
```

Output:

```text
5
4
3
2
1
```

#### Important: `range()` does not include the stop value

| Expression | Generated values |
| :--- | :--- |
| `range(5)` | `0, 1, 2, 3, 4` |
| `range(1, 5)` | `1, 2, 3, 4` |
| `range(1, 10, 2)` | `1, 3, 5, 7, 9` |
| `range(10, 0, -2)` | `10, 8, 6, 4, 2` |

In Python 3, `range()` returns a range object rather than immediately creating a list of all its values.

You can convert it into a list:

```python
numbers = list(range(1, 6))

print(numbers)
```

Output:

```text
[1, 2, 3, 4, 5]
```

### 6.3 Practical examples of `for` loops

#### Example 1: Sum of numbers from 1 to 10

```python
total = 0

for i in range(1, 11):
    total += i

print("Sum:", total)
```

Output:

```text
Sum: 55
```

#### Example 2: Multiplication table

```python
number = 5

for i in range(1, 11):
    print(number, "x", i, "=", number * i)
```

Output:

```text
5 x 1 = 5
5 x 2 = 10
5 x 3 = 15
5 x 4 = 20
5 x 5 = 25
5 x 6 = 30
5 x 7 = 35
5 x 8 = 40
5 x 9 = 45
5 x 10 = 50
```

#### Example 3: Iterating through a string

```python
word = "Python"

for character in word:
    print(character)
```

Output:

```text
P
y
t
h
o
n
```

#### Example 4: Iterating through a dictionary

```python
student = {
    "name": "Rahul",
    "age": 21,
    "course": "Python"
}

for key, value in student.items():
    print(key, ":", value)
```

Output:

```text
name : Rahul
age : 21
course : Python
```

#### Example 5: Using `enumerate()`

Sometimes we need both the index and the value while iterating through a sequence.

```python
fruits = ["Apple", "Banana", "Mango"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
```

Output:

```text
0 Apple
1 Banana
2 Mango
```

We can also specify a starting index:

```python
for index, fruit in enumerate(fruits, start=1):
    print(index, fruit)
```

Output:

```text
1 Apple
2 Banana
3 Mango
```
