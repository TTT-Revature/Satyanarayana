## 11. `input()` and `print()`

Python provides built-in functions for receiving input from users and displaying output.

The two most commonly used functions are:

* `input()` – receives input from the user.
* `print()` – displays information on the screen.

### 11.1 The `input()` function

The `input()` function allows users to enter information while a program is running.

Syntax:

```python
variable = input("Prompt message")
```

Example:

```python
name = input("Enter your name: ")

print(name)
```

Sample execution:

```text
Enter your name: Rahul
Rahul
```

The entered value is stored in the `name` variable.

#### Important: `input()` always returns a string

Even if the user enters a number, Python initially treats the input as a string.

Example:

```python
age = input("Enter your age: ")

print(type(age))
```

If the user enters `21`, the output is:

```text
<class 'str'>
```

To perform mathematical operations, convert the input into the appropriate numeric type.

#### Taking integer input

```python
age = int(input("Enter your age: "))

print(age + 5)
```

If the user enters `21`:

```text
26
```

#### Taking floating-point input

```python
salary = float(input("Enter salary: "))

print(salary)
```

If the user enters `25000.50`, the output is:

```text
25000.5
```

#### Taking multiple inputs in one line

Python's `split()` method separates a string into multiple parts.

```python
a, b = input("Enter two numbers: ").split()

print(a)
print(b)
```

Sample input:

```text
10 20
```

Output:

```text
10
20
```

Both values are strings.

To receive integers:

```python
a, b = map(int, input("Enter two numbers: ").split())

print(a + b)
```

Input:

```text
10 20
```

Output:

```text
30
```

Explanation:

* `input()` reads the entire line as a string.
* `split()` separates it using whitespace by default.
* `map(int, ...)` converts each separated value to an integer.
* The values are unpacked into `a` and `b`.

#### Taking a list of integers

```python
numbers = list(map(int, input("Enter numbers: ").split()))

print(numbers)
```

Input:

```text
10 20 30 40 50
```

Output:

```text
[10, 20, 30, 40, 50]
```

This approach is commonly used in competitive programming and coding assessments.

### 11.2 The `print()` function

The `print()` function displays output on the screen.

Syntax:

```python
print(*objects, sep=' ', end='\n')
```

Important parameters:

| Parameter | Purpose |
| :--- | :--- |
| `*objects` | Values to display |
| `sep` | Separator between multiple values |
| `end` | Character or string printed at the end |

#### Printing multiple values

```python
name = "Rahul"
age = 21

print(name, age)
```

Output:

```text
Rahul 21
```

By default, Python separates multiple arguments with a space.

#### Using `sep`

The `sep` parameter changes the separator.

```python
print("Python", "Java", "C++", sep="-")
```

Output:

```text
Python-Java-C++
```

Another example:

```python
print(10, 20, 30, sep=", ")
```

Output:

```text
10, 20, 30
```

#### Using `end`

By default, `print()` adds a newline after displaying the output.

```python
print("Hello")
print("World")
```

Output:

```text
Hello
World
```

If we use `end`, we can change this behavior.

```python
print("Hello", end=" ")
print("World")
```

Output:

```text
Hello World
```

#### Printing without a newline

```python
for i in range(1, 6):
    print(i, end=" ")
```

Output:

```text
1 2 3 4 5
```

#### Printing special characters

Python supports escape sequences.

| Escape sequence | Meaning |
| :--- | :--- |
| `\n` | New line |
| `\t` | Tab space |
| `\\` | Backslash |
| `\'` | Single quotation mark |
| `\"` | Double quotation mark |

Example:

```python
print("Hello\nWorld")
print("Name:\tRahul")
```

Output:

```text
Hello
World
Name:   Rahul
```

### 11.3 Practical example: User information

```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))
city = input("Enter your city: ")

print("----- Student Information -----")
print("Name:", name)
print("Age:", age)
print("City:", city)
```

Sample input:

```text
Enter your name: Rahul
Enter your age: 21
Enter your city: Hyderabad
```

Output:

```text
----- Student Information -----
Name: Rahul
Age: 21
City: Hyderabad
```

### 11.4 Handling invalid numeric input

If a user enters text when an integer is expected, `int()` raises a `ValueError`.

Example:

```python
age = int(input("Enter your age: "))
```

If the user enters `twenty`, the program raises an error.

We can handle this using exception handling:

```python
try:
    age = int(input("Enter your age: "))
    print("Your age is:", age)

except ValueError:
    print("Please enter a valid integer")
```

This makes the program more robust.
