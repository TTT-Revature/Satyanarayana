## 10. Loop `else`

Python provides an interesting feature called the `else` clause with loops.

Both `for` and `while` loops can have an `else` block.

The loop's `else` block executes when the loop finishes normally, without being terminated by a `break` statement.

### 10.1 `else` with a `for` loop

Syntax:

```python
for variable in sequence:
    statements
else:
    statements
```

Example:

```python
for i in range(1, 6):
    print(i)
else:
    print("Loop completed")
```

Output:

```text
1
2
3
4
5
Loop completed
```

The loop completes all iterations, so the `else` block executes.

### 10.2 `else` with `break`

```python
for i in range(1, 6):
    if i == 3:
        break

    print(i)
else:
    print("Loop completed")
```

Output:

```text
1
2
```

The `break` statement terminates the loop. Therefore, the loop's `else` block does not execute.

### 10.3 `else` with `continue`

A `continue` statement does not prevent the loop's `else` block from executing.

```python
for i in range(1, 6):
    if i == 3:
        continue

    print(i)
else:
    print("Loop completed")
```

Output:

```text
1
2
4
5
Loop completed
```

The loop completed normally, even though one iteration was skipped.

### 10.4 `else` with a `while` loop

```python
count = 1

while count <= 3:
    print(count)
    count += 1
else:
    print("While loop completed")
```

Output:

```text
1
2
3
While loop completed
```

### 10.5 Practical example: Prime number checking

A prime number is a number greater than 1 that has exactly two factors: 1 and itself.

We can use a loop's `else` block to check whether a number is prime.

```python
number = 17

if number <= 1:
    print("Not a prime number")
else:
    for i in range(2, number):
        if number % i == 0:
            print("Not a prime number")
            break
    else:
        print("Prime number")
```

Output:

```text
Prime number
```

Explanation:

* Python checks whether the number is greater than 1.
* The `for` loop checks whether any number from 2 to 16 divides 17.
* If a divisor is found, `break` executes.
* If no divisor is found, the loop completes normally.
* The `else` block executes and prints `Prime number`.

A more efficient version checks divisors only up to the square root of the number:

```python
number = 17

if number <= 1:
    print("Not prime")
else:
    for i in range(2, int(number ** 0.5) + 1):
        if number % i == 0:
            print("Not prime")
            break
    else:
        print("Prime")
```

### Important points

* Loop `else` is different from conditional `if-else`.
* The loop `else` executes if the loop finishes normally.
* The loop `else` does not execute when the loop exits through `break`.
* A `continue` statement does not prevent the `else` block from executing.
* If a `while` loop stops because its condition becomes false, its `else` block executes.
