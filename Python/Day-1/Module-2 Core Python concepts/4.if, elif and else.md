## 4. `if`, `elif` and `else`

Conditional statements allow a program to make decisions based on whether a condition is true or false.

In real life, we make decisions every day:

* If it rains, take an umbrella.
* If marks are above 90, assign grade A.
* Otherwise, assign another grade.

Python uses `if`, `elif`, and `else` to implement this decision-making logic.

### 4.1 The `if` statement

The `if` statement executes a block of code only when its condition is true.

Syntax:

```python
if condition:
    statement
```

Example:

```python
age = 20

if age >= 18:
    print("You are eligible to vote")
```

Output:

```text
You are eligible to vote
```

Explanation:

* Python checks whether `age >= 18`.
* The condition evaluates to `True`.
* Python executes the indented statement.

If the condition is false, the block is skipped.

```python
age = 15

if age >= 18:
    print("Eligible to vote")

print("Program completed")
```

Output:

```text
Program completed
```

### 4.2 The `if-else` statement

The `else` statement executes when the `if` condition is false.

Syntax:

```python
if condition:
    statement1
else:
    statement2
```

Example:

```python
number = 7

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

Output:

```text
Odd number
```

Only one of the two blocks executes.

### 4.3 The `if-elif-else` statement

The `elif` keyword means "else if". It allows us to check multiple conditions.

Syntax:

```python
if condition1:
    statement1
elif condition2:
    statement2
elif condition3:
    statement3
else:
    default_statement
```

Python checks conditions from top to bottom. As soon as it finds a true condition, it executes that block and skips the remaining branches.

Example: Student grading system.

```python
marks = 85

if marks >= 90:
    print("Grade A")
elif marks >= 80:
    print("Grade B")
elif marks >= 70:
    print("Grade C")
elif marks >= 60:
    print("Grade D")
else:
    print("Fail")
```

Output:

```text
Grade B
```

Explanation:

* Is 85 greater than or equal to 90? No.
* Is 85 greater than or equal to 80? Yes.
* Python prints `Grade B` and skips the remaining conditions.

### 4.4 Real-world example: Login validation

```python
username = "admin"
password = "python123"

if username == "admin" and password == "python123":
    print("Login successful")
else:
    print("Invalid username or password")
```

Output:

```text
Login successful
```

### 4.5 Important points

* A condition must be followed by a colon (`:`).
* The statements inside a block must be indented.
* You can use multiple `elif` branches.
* An `else` branch is optional.
* An `if` statement can exist without `else` or `elif`.
* Only the first matching branch in an `if-elif-else` chain executes.
