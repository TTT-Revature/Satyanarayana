## 2. Logical, Membership and Identity Operators

These operators are used to combine conditions, check whether values exist in a collection, and determine whether two references point to the same object.

### 2.1 Logical operators

Logical operators combine multiple conditions and return `True` or `False`.

Python provides three logical operators:

* `and`
* `or`
* `not`

#### 1. AND (`and`)

Returns `True` only when both conditions are true.

| Condition 1 | Condition 2 | Result |
| :--- | :--- | :--- |
| `True` | `True` | `True` |
| `True` | `False` | `False` |
| `False` | `True` | `False` |
| `False` | `False` | `False` |

Example:

```python
age = 22
has_id = True

if age >= 18 and has_id:
    print("Entry allowed")
else:
    print("Entry denied")
```

Output:

```text
Entry allowed
```

Both conditions must be satisfied.

#### 2. OR (`or`)

Returns `True` if at least one condition is true.

| Condition 1 | Condition 2 | Result |
| :--- | :--- | :--- |
| `True` | `True` | `True` |
| `True` | `False` | `True` |
| `False` | `True` | `True` |
| `False` | `False` | `False` |

Example:

```python
day = "Sunday"

if day == "Saturday" or day == "Sunday":
    print("Weekend")
else:
    print("Weekday")
```

Output:

```text
Weekend
```

#### 3. NOT (`not`)

Reverses the Boolean value.

| Condition | Result |
| :--- | :--- |
| `True` | `False` |
| `False` | `True` |

Example:

```python
is_raining = False

if not is_raining:
    print("Go outside")
else:
    print("Stay indoors")
```

Output:

```text
Go outside
```

#### Short-circuit evaluation

Python does not always evaluate every condition in a logical expression.

* With `and`, if the first condition is false, Python does not need to evaluate the second condition.
* With `or`, if the first condition is true, Python does not need to evaluate the second condition.

Example:

```python
x = 0

if x != 0 and 10 / x > 2:
    print("Condition satisfied")
else:
    print("Condition not satisfied")
```

Output:

```text
Condition not satisfied
```

The division is not executed because the first condition is false. This prevents a division-by-zero error.

### 2.2 Membership operators

Membership operators check whether an element exists in a sequence or collection.

Python provides:

* `in`
* `not in`

#### 1. IN (`in`)

Returns `True` if an element exists in a collection.

```python
fruits = ["apple", "banana", "mango"]

print("apple" in fruits)
print("orange" in fruits)
```

Output:

```text
True
False
```

#### 2. NOT IN (`not in`)

Returns `True` if an element does not exist in a collection.

```python
fruits = ["apple", "banana", "mango"]

print("orange" not in fruits)
print("banana" not in fruits)
```

Output:

```text
True
False
```

#### Membership with strings

```python
message = "Python Programming"

print("Python" in message)
print("Java" in message)
```

Output:

```text
True
False
```

String membership is case-sensitive:

```python
print("python" in "Python")
```

Output:

```text
False
```

#### Membership with dictionaries

For dictionaries, `in` checks keys by default, not values.

```python
student = {
    "name": "Rahul",
    "age": 21,
    "course": "Python"
}

print("name" in student)
print("Rahul" in student)
print("Rahul" in student.values())
```

Output:

```text
True
False
True
```

### 2.3 Identity operators

Identity operators check whether two variables refer to the exact same object in memory.

Python provides:

* `is`
* `is not`

#### 1. IS (`is`)

Returns `True` when both variables refer to the same object.

```python
a = [10, 20, 30]
b = a

print(a is b)
```

Output:

```text
True
```

Both variables refer to the same list.

#### 2. IS NOT (`is not`)

Returns `True` when two variables refer to different objects.

```python
a = [10, 20, 30]
b = [10, 20, 30]

print(a is not b)
```

Output:

```text
True
```

Although both lists contain identical values, they are two separate objects.

#### Difference between `==` and `is`

This is an important interview question.

* `==` checks whether values are equal.
* `is` checks whether two references point to the same object.

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)
print(a is b)

print(a == c)
print(a is c)
```

Output:

```text
True
False
True
True
```

**Remember this distinction:**

* `a == b` $\rightarrow$ Same values
* `a is b` $\rightarrow$ Different objects

In the example, `a` and `b` contain equal lists but are separate objects.

#### When should you use `is`?

A common and recommended use is checking against `None`.

```python
result = None

if result is None:
    print("No result available")
```

Output:

```text
No result available
```

Do not generally use `is` to compare ordinary strings or numbers. Use `==` when you want to compare their values.
