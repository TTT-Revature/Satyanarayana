## 14. `argparse`

`argparse` is a Python standard-library module used to create command-line interfaces (CLIs).

It allows users to provide arguments and options when running Python programs from a terminal.

It is more powerful than `sys.argv` because it provides:

* Automatic argument parsing.
* Input type conversion.
* Required and optional arguments.
* Default values.
* Input validation.
* Automatic help messages.
* Meaningful error messages.

### 14.1 Why do we need `argparse`?

Consider a program that adds two numbers.

Using `sys.argv`:

```python
import sys

a = int(sys.argv[1])
b = int(sys.argv[2])

print("Sum:", a + b)
```

Run:

```bash
python add.py 10 20
```

Output:

```text
Sum: 30
```

The problem is that we must manually handle missing arguments, invalid input, and argument positions.

Using `argparse`, Python handles much of this automatically.

### 14.2 Basic `argparse` example

Create a file named `add.py`.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("num1", type=int)
parser.add_argument("num2", type=int)

args = parser.parse_args()

print("Sum:", args.num1 + args.num2)
```

Run:

```bash
python add.py 10 20
```

Output:

```text
Sum: 30
```

#### Understanding the code

**Step 1:** Import `argparse`

```python
import argparse
```

Imports the built-in module.

**Step 2:** Create an argument parser

```python
parser = argparse.ArgumentParser()
```

Creates an object responsible for processing command-line arguments.

**Step 3:** Add arguments

```python
parser.add_argument("num1", type=int)
parser.add_argument("num2", type=int)
```

Defines two positional arguments.

* `num1` is the first argument.
* `num2` is the second argument.
* `type=int` converts the supplied values into integers.

**Step 4:** Parse the arguments

```python
args = parser.parse_args()
```

Reads the command-line arguments and stores them in an object.

**Step 5:** Access the arguments

```python
print(args.num1 + args.num2)
```

We can access the values using their argument names.

### 14.3 Positional arguments

Positional arguments are arguments that must be provided in a particular order.

Example:

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("name")
parser.add_argument("age", type=int)

args = parser.parse_args()

print(f"Name: {args.name}")
print(f"Age: {args.age}")
```

Run:

```bash
python student.py Rahul 21
```

Output:

```text
Name: Rahul
Age: 21
```

If the required arguments are missing, `argparse` automatically displays an error message.

### 14.4 Optional arguments

Optional arguments are not mandatory. They are generally specified using a prefix such as `--`.

Example:

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--name", help="Enter your name")
parser.add_argument("--age", type=int, help="Enter your age")

args = parser.parse_args()

print("Name:", args.name)
print("Age:", args.age)
```

Run:

```bash
python student.py --name Rahul --age 21
```

Output:

```text
Name: Rahul
Age: 21
```

You can also provide the arguments in a different order:

```bash
python student.py --age 21 --name Rahul
```

The output remains the same.

### 14.5 Default values

We can specify default values for optional arguments.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--name", default="Guest")
parser.add_argument("--age", type=int, default=18)

args = parser.parse_args()

print(f"Name: {args.name}")
print(f"Age: {args.age}")
```

Run without arguments:

```bash
python student.py
```

Output:

```text
Name: Guest
Age: 18
```

Run with arguments:

```bash
python student.py --name Rahul --age 22
```

Output:

```text
Name: Rahul
Age: 22
```

### 14.6 Required optional arguments

Sometimes we want to use the `--option` format but still require the user to provide it.

We can use `required=True`.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--username", required=True)

args = parser.parse_args()

print("Username:", args.username)
```

Run:

```bash
python login.py --username Rahul
```

Output:

```text
Username: Rahul
```

If `--username` is omitted, the program displays an error.

### 14.7 Choices for validation

The `choices` parameter restricts an argument to a predefined set of values.

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument(
    "--environment",
    choices=["development", "testing", "production"],
    default="development"
)

args = parser.parse_args()

print("Environment:", args.environment)
```

Run:

```bash
python app.py --environment production
```

Output:

```text
Environment: production
```

If the user provides an invalid choice:

```bash
python app.py --environment staging
```

`argparse` reports that `staging` is not an accepted choice.

This is useful when building deployment scripts and configuration tools.

### 14.8 Boolean flags with action

A Boolean flag can be used to enable or disable an option.

Example:

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument(
    "--verbose",
    action="store_true",
    help="Enable detailed output"
)

args = parser.parse_args()

if args.verbose:
    print("Detailed output enabled")
else:
    print("Normal output")
```

Run without the flag:

```bash
python app.py
```

Output:

```text
Normal output
```

Run with the flag:

```bash
python app.py --verbose
```

Output:

```text
Detailed output enabled
```

`store_true` means the value is `False` by default and becomes `True` when the flag is supplied.

### 14.9 Adding descriptions and help messages

One of the most useful features of `argparse` is automatic help generation.

```python
import argparse

parser = argparse.ArgumentParser(
    description="A simple student information application"
)

parser.add_argument(
    "--name",
    required=True,
    help="Name of the student"
)

parser.add_argument(
    "--age",
    type=int,
    required=True,
    help="Age of the student"
)

args = parser.parse_args()

print(f"Student: {args.name}, Age: {args.age}")
```

Run:

```bash
python student.py --help
```

Example output:

```text
usage: student.py [-h] --name NAME --age AGE

A simple student information application

options:
  -h, --help   show this help message and exit
  --name NAME  Name of the student
  --age AGE    Age of the student
```

The help message is generated automatically from the parser configuration.

### 14.10 Practical example: Command-line calculator

This example combines positional arguments, choices, type conversion, and error handling.

```python
import argparse

parser = argparse.ArgumentParser(
    description="Command-line calculator"
)

parser.add_argument("num1", type=float, help="First number")
parser.add_argument("operator", choices=["+", "-", "*", "/"])
parser.add_argument("num2", type=float, help="Second number")

args = parser.parse_args()

if args.operator == "+":
    result = args.num1 + args.num2

elif args.operator == "-":
    result = args.num1 - args.num2

elif args.operator == "*":
    result = args.num1 * args.num2

elif args.operator == "/":
    if args.num2 == 0:
        parser.error("Division by zero is not allowed")

    result = args.num1 / args.num2

print("Result:", result)
```

Run:

```bash
python calculator.py 10 + 20
```

Output:

```text
Result: 30.0
```

Another execution:

```bash
python calculator.py 50 / 5
```

Output:

```text
Result: 10.0
```

### Common `argparse` methods and parameters

| Method / Parameter | Purpose |
| :--- | :--- |
| `ArgumentParser()` | Creates the parser |
| `add_argument()` | Defines an argument |
| `parse_args()` | Parses the command-line input |
| `type` | Converts an argument to a specified type |
| `default` | Sets a default value |
| `required` | Makes an optional-style argument mandatory |
| `choices` | Restricts allowed values |
| `help` | Adds help information |
| `action="store_true"` | Creates a Boolean flag |
| `description` | Describes the application |
| `parser.error()` | Displays an error and exits |

## 15. Difference Between `input()`, `sys.argv` and `argparse`

All three approaches allow us to provide input to a Python program, but they are used in different situations.

| Feature | `input()` | `sys.argv` | `argparse` |
| :--- | :--- | :--- | :--- |
| **Input method** | During program execution | While launching the program | While launching the program |
| **Input source** | User interaction | Command line | Command line |
| **Returns** | String | List of strings | Parsed argument namespace |
| **Type conversion** | Manual | Manual | Supported through `type` |
| **Validation** | Manual | Manual | Built-in options |
| **Help message** | No automatic help | No automatic help | Automatic |
| **Default values** | Manual | Manual | Supported |
| **Best suited for** | Interactive applications | Small command-line scripts | Professional CLI applications |

### Understanding the difference through examples

**Using `input()`:**

```python
name = input("Enter name: ")

print("Hello", name)
```

Run:

```bash
python app.py
```

The program asks the user to enter their name after it starts.

**Using `sys.argv`:**

```python
import sys

name = sys.argv[1]

print("Hello", name)
```

Run:

```bash
python app.py Rahul
```

The name is provided when starting the program.

**Using `argparse`:**

```python
import argparse

parser = argparse.ArgumentParser()

parser.add_argument("--name", required=True)

args = parser.parse_args()

print("Hello", args.name)
```

Run:

```bash
python app.py --name Rahul
```

The name is provided as a named command-line option, with automatic argument handling.
