## 7. `while` Loops

A `while` loop repeatedly executes a block of code as long as its condition remains true.

Unlike a `for` loop, which commonly iterates over a sequence, a `while` loop is useful when the number of repetitions is not known in advance.

Syntax:

```python
while condition:
    statements
```

### 7.1 Basic example

```python
count = 1

while count <= 5:
    print(count)
    count += 1
```

Output:

```text
1
2
3
4
5
```

Explanation:

* `count` starts at 1.
* Python checks whether `count <= 5`.
* If true, the loop body executes.
* `count` is incremented by 1.
* The condition is checked again.
* When `count` becomes 6, the condition becomes false and the loop stops.

### 7.2 Infinite loops

An infinite loop occurs when the loop condition never becomes false.

Example:

```python
while True:
    print("Hello")
```

This program keeps printing `Hello` until it is interrupted or explicitly terminated.

Infinite loops can be useful for applications that continuously wait for input or events, but they should have an appropriate exit mechanism.

### 7.3 Practical examples

#### Example 1: Countdown

```python
count = 5

while count >= 1:
    print(count)
    count -= 1

print("Go!")
```

Output:

```text
5
4
3
2
1
Go!
```

#### Example 2: Sum of digits

```python
number = 1234
total = 0

while number > 0:
    digit = number % 10
    total += digit
    number //= 10

print("Sum of digits:", total)
```

Output:

```text
Sum of digits: 10
```

Explanation:

| Iteration | Number | Extracted digit | Total |
| :--- | :--- | :--- | :--- |
| 1 | `1234` | `4` | `4` |
| 2 | `123` | `3` | `7` |
| 3 | `12` | `2` | `9` |
| 4 | `1` | `1` | `10` |

#### Example 3: Password validation

```python
correct_password = "python123"

password = input("Enter password: ")

while password != correct_password:
    print("Incorrect password")
    password = input("Try again: ")

print("Login successful")
```

The loop continues until the correct password is entered.

### 7.4 Difference between `for` and `while`

| Feature | `for` loop | `while` loop |
| :--- | :--- | :--- |
| **Purpose** | Iterate over an iterable | Repeat while a condition is true |
| **Common use** | Known sequence or number of iterations | Condition-based repetition |
| **Initialization** | Usually handled by the iterable | Often done before the loop |
| **Update** | Usually handled by iteration | Often written inside the loop |
| **Risk of infinite loop** | Generally lower | Higher if condition is not updated |

Example:

* Use a `for` loop when printing numbers from 1 to 10.
* Use a `while` loop when repeatedly asking the user to enter a valid password.
