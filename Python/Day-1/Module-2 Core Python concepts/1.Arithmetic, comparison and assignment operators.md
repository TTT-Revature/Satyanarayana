## 1. Arithmetic, Comparison and Assignment Operators

Operators are special symbols or keywords that perform operations on variables and values.

For example:

```python
a = 10
b = 5

print(a + b)
```

Output:

```text
15
```

Here, `+` is an operator, and `a` and `b` are operands.

Python operators can be classified into several categories.

### 1.1 Arithmetic operators

Arithmetic operators are used to perform mathematical calculations such as addition, subtraction, multiplication, and division.

Assume:

```python
a = 10
b = 3
```

| Operator | Name | Example | Result |
| :--- | :--- | :--- | :--- |
| `+` | Addition | `a + b` | `13` |
| `-` | Subtraction | `a - b` | `7` |
| `*` | Multiplication | `a * b` | `30` |
| `/` | Division | `a / b` | `3.3333...` |
| `//` | Floor division | `a // b` | `3` |
| `%` | Modulus | `a % b` | `1` |
| `**` | Exponentiation | `a ** b` | `1000` |

#### 1. Addition (`+`)

Adds two values.

```python
a = 10
b = 20

result = a + b
print(result)
```

Output:

```text
30
```

#### 2. Subtraction (`-`)

Subtracts the second value from the first.

```python
a = 20
b = 10

print(a - b)
```

Output:

```text
10
```

#### 3. Multiplication (`*`)

Multiplies two values.

```python
a = 5
b = 4

print(a * b)
```

Output:

```text
20
```

#### 4. Division (`/`)

Divides one number by another. In Python, `/` always returns a floating-point result, even when the division is exact.

```python
print(10 / 2)
print(7 / 2)
```

Output:

```text
5.0
3.5
```

#### 5. Floor division (`//`)

Returns the quotient rounded down to the nearest integer value.

```python
print(10 // 3)
print(7 // 2)
print(-7 // 2)
```

Output:

```text
3
3
-4
```

> **Note:** Notice that floor division rounds down, not simply toward zero. Therefore, `-7 // 2` produces `-4`.

#### 6. Modulus (`%`)

Returns the remainder after division.

```python
print(10 % 3)
print(15 % 4)
```

Output:

```text
1
3
```

Common practical application: checking whether a number is even or odd.

```python
number = 12

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

Output:

```text
Even number
```

#### 7. Exponentiation (`**`)

Raises a number to a power.

```python
print(2 ** 3)
print(5 ** 2)
```

Output:

```text
8
25
```

#### Practical example: Simple calculator

```python
a = 20
b = 5

print("Addition:", a + b)
print("Subtraction:", a - b)
print("Multiplication:", a * b)
print("Division:", a / b)
print("Floor Division:", a // b)
print("Remainder:", a % b)
print("Power:", a ** b)
```

### 1.2 Comparison operators

Comparison operators compare two values and return a Boolean result: `True` or `False`.

Assume:

```python
a = 10
b = 20
```

| Operator | Meaning | Example | Result |
| :--- | :--- | :--- | :--- |
| `==` | Equal to | `a == b` | `False` |
| `!=` | Not equal to | `a != b` | `True` |
| `>` | Greater than | `a > b` | `False` |
| `<` | Less than | `a < b` | `True` |
| `>=` | Greater than or equal to | `a >= b` | `False` |
| `<=` | Less than or equal to | `a <= b` | `True` |

Example:

```python
age = 20

print(age == 20)
print(age != 18)
print(age > 18)
print(age < 18)
print(age >= 20)
print(age <= 25)
```

Output:

```text
True
True
True
False
True
True
```

#### Difference between `=` and `==`

This is one of the most important concepts for beginners.

* `=` is an assignment operator. It assigns a value to a variable.
* `==` is a comparison operator. It checks whether two values are equal.

```python
age = 21

print(age == 21)
```

Output:

```text
True
```

#### Chained comparisons

Python allows multiple comparisons in a single expression.

```python
age = 22

print(18 <= age <= 60)
```

Output:

```text
True
```

This is equivalent to:

```python
print(18 <= age and age <= 60)
```

It is useful when checking whether a value falls within a range.

### 1.3 Assignment operators

Assignment operators are used to assign values to variables and update their existing values.

| Operator | Example | Equivalent expression |
| :--- | :--- | :--- |
| `=` | `x = 10` | Assign `10` to `x` |
| `+=` | `x += 5` | `x = x + 5` |
| `-=` | `x -= 5` | `x = x - 5` |
| `*=` | `x *= 5` | `x = x * 5` |
| `/=` | `x /= 5` | `x = x / 5` |
| `//=` | `x //= 5` | `x = x // 5` |
| `%=` | `x %= 5` | `x = x % 5` |
| `**=` | `x **= 5` | `x = x ** 5` |

Example:

```python
x = 10

x += 5
print(x)

x -= 3
print(x)

x *= 2
print(x)

x //= 4
print(x)
```

Output:

```text
15
12
24
6
```

#### Important: Assignment does not always mean making a copy

Consider:

```python
a = [10, 20, 30]
b = a

b.append(40)

print(a)
print(b)
```

Output:

```text
[10, 20, 30, 40]
[10, 20, 30, 40]
```

Both variables refer to the same list object. Assignment does not automatically create a new copy of a mutable object.
