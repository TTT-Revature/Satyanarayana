## 5. Nested Conditions and Conditional Expressions

### 5.1 Nested conditions

A nested condition means placing one conditional statement inside another conditional statement.

This is useful when a decision depends on multiple levels of checks.

Syntax:

```python
if condition1:
    if condition2:
        statement1
    else:
        statement2
else:
    statement3
```

#### Example 1: Voting eligibility with citizenship

```python
age = 25
citizen = True

if age >= 18:
    if citizen:
        print("Eligible to vote")
    else:
        print("Must be a citizen to vote")
else:
    print("Not eligible due to age")
```

Output:

```text
Eligible to vote
```

Explanation:

* First, Python checks whether the person's age is at least 18.
* If true, Python checks whether the person is a citizen.
* If both conditions are true, the person is eligible.

#### Example 2: Login system

```python
username = "admin"
password = "python123"
otp = 1234

if username == "admin":
    if password == "python123":
        if otp == 1234:
            print("Login successful")
        else:
            print("Invalid OTP")
    else:
        print("Incorrect password")
else:
    print("Invalid username")
```

Output:

```text
Login successful
```

This example demonstrates three levels of nested conditions.

#### Example 3: Finding the largest of three numbers

```python
a = 30
b = 50
c = 20

if a > b:
    if a > c:
        print("A is largest")
    else:
        print("C is largest")
else:
    if b > c:
        print("B is largest")
    else:
        print("C is largest")
```

Output:

```text
B is largest
```

#### Nested conditions vs logical operators

Sometimes nested conditions can be simplified using logical operators.

Nested version:

```python
age = 22
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")
```

Simplified version:

```python
if age >= 18 and has_id:
    print("Entry allowed")
```

Both versions perform the same checks in this example.

Use nested conditions when the inner decision should only be considered after an outer condition succeeds. Use logical operators when combining straightforward conditions makes the code easier to read.

### 5.2 Conditional expressions (ternary operator)

A conditional expression is a shorter way to write a simple `if-else` statement.

It is also called a ternary conditional expression because it uses three parts:

* The value returned when the condition is true.
* The condition.
* The value returned when the condition is false.

Syntax:

```python
value_if_true if condition else value_if_false
```

#### Example 1: Even or odd

Traditional approach:

```python
number = 10

if number % 2 == 0:
    result = "Even"
else:
    result = "Odd"

print(result)
```

Conditional expression:

```python
number = 10

result = "Even" if number % 2 == 0 else "Odd"

print(result)
```

Output:

```text
Even
```

#### Example 2: Find the largest number

```python
a = 20
b = 30

largest = a if a > b else b

print("Largest:", largest)
```

Output:

```text
Largest: 30
```

#### Example 3: Pass or fail

```python
marks = 45

result = "Pass" if marks >= 40 else "Fail"

print(result)
```

Output:

```text
Pass
```

#### Nested conditional expressions

Conditional expressions can also be nested.

```python
marks = 75

grade = "A" if marks >= 90 else "B" if marks >= 75 else "C"

print(grade)
```

Output:

```text
B
```

Although this is valid, avoid deeply nested conditional expressions because they become difficult to understand.

**When should you use conditional expressions?**
Use them for simple decisions that fit naturally into one line. Prefer normal `if-elif-else` statements for complicated decision-making.
