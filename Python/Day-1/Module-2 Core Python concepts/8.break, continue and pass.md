## 8. `break`, `continue` and `pass`

These are control-flow statements used to change how Python executes loops or blocks.

### 8.1 The `break` statement

The `break` statement immediately terminates the nearest enclosing loop.

Example:

```python
for i in range(1, 10):
    if i == 5:
        break

    print(i)
```

Output:

```text
1
2
3
4
```

Explanation:

* The loop starts at 1.
* It prints 1, 2, 3, and 4.
* When `i` becomes 5, the `break` statement executes.
* The loop terminates immediately.

#### Practical example: Search for an element

```python
numbers = [10, 20, 30, 40, 50]

target = 30

for number in numbers:
    if number == target:
        print("Element found")
        break
```

Output:

```text
Element found
```

There is no need to continue searching after the target is found.

### 8.2 The `continue` statement

The `continue` statement skips the remaining statements in the current iteration and moves to the next iteration.

Example:

```python
for i in range(1, 6):
    if i == 3:
        continue

    print(i)
```

Output:

```text
1
2
4
5
```

Explanation:

* The loop prints 1 and 2.
* When `i` becomes 3, `continue` executes.
* The `print()` statement is skipped for that iteration.
* The loop continues with 4 and 5.

#### Practical example: Print only even numbers

```python
for i in range(1, 11):
    if i % 2 != 0:
        continue

    print(i)
```

Output:

```text
2
4
6
8
10
```

### 8.3 The `pass` statement

The `pass` statement does nothing. It acts as a placeholder when Python syntax requires a statement but you do not want to implement the logic yet.

Example:

```python
if True:
    pass

print("Program continues")
```

Output:

```text
Program continues
```

#### Practical example: Function placeholder

```python
def calculate_salary():
    pass

print("Function created")
```

Output:

```text
Function created
```

Here, the function has been declared, but its implementation has not yet been written.

### 8.4 Difference between `break`, `continue` and `pass`

| Statement | Purpose | Effect |
| :--- | :--- | :--- |
| `break` | Terminate the loop | Exits the nearest loop |
| `continue` | Skip the current iteration | Moves to the next iteration |
| `pass` | Do nothing | Execution continues normally |

#### Combined example

```python
for i in range(1, 8):

    if i == 2:
        continue

    if i == 5:
        break

    if i == 3:
        pass

    print(i)
```

Output:

```text
1
3
4
```

Explanation:

* `1` is printed.
* `2` is skipped because of `continue`.
* `3` reaches `pass`, which does nothing, so it is printed.
* `4` is printed.
* `5` causes the loop to terminate because of `break`.
