## 13. `sys.argv`

So far, we have learned to receive input using the `input()` function.

However, Python also allows us to provide input when starting a program from the command line.

This is called command-line argument handling.

The `sys.argv` list is provided by Python's built-in `sys` module.

It stores the command-line arguments passed to the Python program.

### 13.1 What is `sys.argv`?

`sys.argv` is a list containing command-line arguments.

* `sys.argv[0]` contains the script name.
* `sys.argv[1]` contains the first command-line argument.
* `sys.argv[2]` contains the second command-line argument.
* Additional arguments are stored at subsequent indexes.

Example program:

Create a file named `demo.py`.

```python
import sys

print(sys.argv)
```

Run the program from a terminal:

```bash
python demo.py Rahul 21 Hyderabad
```

Output will be similar to:

```text
['demo.py', 'Rahul', '21', 'Hyderabad']
```

The exact script path shown at index 0 can vary depending on how the program is launched.

### 13.2 Accessing individual arguments

```python
import sys

print("Script:", sys.argv[0])
print("Name:", sys.argv[1])
print("Age:", sys.argv[2])
print("City:", sys.argv[3])
```

Run:

```bash
python demo.py Rahul 21 Hyderabad
```

Output:

```text
Script: demo.py
Name: Rahul
Age: 21
City: Hyderabad
```

### 13.3 Command-line arguments are strings

This is an important point.

Even if the user passes a number, `sys.argv` stores it as a string.

Example:

```python
import sys

age = sys.argv[1]

print(type(age))
```

Run:

```bash
python demo.py 21
```

Output:

```text
<class 'str'>
```

To perform mathematical operations, convert it into an integer.

```python
import sys

a = int(sys.argv[1])
b = int(sys.argv[2])

print("Sum:", a + b)
```

Run:

```bash
python demo.py 10 20
```

Output:

```text
Sum: 30
```

### 13.4 Example: Simple command-line calculator

```python
import sys

a = float(sys.argv[1])
operator = sys.argv[2]
b = float(sys.argv[3])

if operator == "+":
    result = a + b

elif operator == "-":
    result = a - b

elif operator == "*":
    result = a * b

elif operator == "/":
    if b != 0:
        result = a / b
    else:
        print("Cannot divide by zero")
        sys.exit(1)

else:
    print("Invalid operator")
    sys.exit(1)

print("Result:", result)
```

Run:

```bash
python calculator.py 10 + 20
```

Output:

```text
Result: 30.0
```

Another example:

```bash
python calculator.py 10 "*" 5
```

Output:

```text
Result: 50.0
```

> **Tip:** Quoting `*` is important in many shells because an unquoted asterisk can be interpreted as a wildcard.

### 13.5 Handling missing arguments

If we access an argument that was not provided, Python raises an `IndexError`.

For example:

```python
import sys

name = sys.argv[1]

print(name)
```

Running:

```bash
python demo.py
```

will cause an error because `sys.argv[1]` does not exist.

We can check the number of arguments before accessing them.

```python
import sys

if len(sys.argv) < 2:
    print("Please provide your name")
else:
    name = sys.argv[1]
    print("Hello", name)
```

Run:

```bash
python demo.py Rahul
```

Output:

```text
Hello Rahul
```

`len(sys.argv)` includes the script name, so a script name plus one user argument gives a length of 2.

### 13.6 Useful `sys` functions

| Function or attribute | Purpose |
| :--- | :--- |
| `sys.argv` | Access command-line arguments |
| `sys.exit()` | Exit the program |
| `sys.version` | Get Python version information |
| `sys.platform` | Get the operating system platform identifier |
| `sys.path` | View module search paths |

Example:

```python
import sys

print("Python version:", sys.version)
print("Platform:", sys.platform)
print("Arguments:", sys.argv)
```

### Limitations of `sys.argv`

Although `sys.argv` is simple, it has limitations:

* It does not automatically validate input.
* It does not automatically convert data types.
* It does not provide built-in help messages for your application's options.
* It requires manual argument indexing and validation.
* It becomes difficult to manage when a program has many command-line options.

For more advanced command-line programs, Python provides `argparse`.
