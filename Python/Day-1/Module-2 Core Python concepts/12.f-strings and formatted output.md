## 12. f-strings and Formatted Output

Formatted output allows us to display variables and expressions inside strings in a readable manner.

Python supports several ways to format strings:

* String concatenation.
* `%` formatting.
* `str.format()`.
* f-strings.

Among these, f-strings are generally the most convenient and readable for modern Python code.

### 12.1 String concatenation

String concatenation means joining multiple strings using the `+` operator.

```python
name = "Rahul"
age = 21

message = "My name is " + name + " and I am " + str(age) + " years old."

print(message)
```

Output:

```text
My name is Rahul and I am 21 years old.
```

Notice that we need `str(age)` because Python cannot directly concatenate a string and an integer.

### 12.2 The `str.format()` method

The `format()` method inserts values into placeholders `{}`.

```python
name = "Rahul"
age = 21

message = "My name is {} and I am {} years old.".format(name, age)

print(message)
```

Output:

```text
My name is Rahul and I am 21 years old.
```

We can also use positional indexes:

```python
message = "My name is {0} and I am {1} years old.".format("Rahul", 21)

print(message)
```

Output:

```text
My name is Rahul and I am 21 years old.
```

We can use named placeholders:

```python
message = "Name: {name}, Age: {age}".format(name="Rahul", age=21)

print(message)
```

Output:

```text
Name: Rahul, Age: 21
```

### 12.3 f-strings

An f-string is a formatted string literal. It allows us to directly insert variables and expressions inside curly braces.

An f-string is created by placing `f` or `F` before the opening quotation mark.

Syntax:

```python
f"Some text {variable}"
```

Example:

```python
name = "Rahul"
age = 21

print(f"My name is {name} and I am {age} years old.")
```

Output:

```text
My name is Rahul and I am 21 years old.
```

This is simpler than string concatenation because explicit type conversion is not required for normal variable interpolation.

### 12.4 Expressions inside f-strings

We can perform calculations directly inside curly braces.

```python
a = 10
b = 20

print(f"Sum = {a + b}")
print(f"Product = {a * b}")
```

Output:

```text
Sum = 30
Product = 200
```

We can also call functions:

```python
name = "rahul"

print(f"Uppercase name: {name.upper()}")
```

Output:

```text
Uppercase name: RAHUL
```

### 12.5 Formatting decimal numbers

Use `.nf` to specify the number of digits after the decimal point.

```python
price = 123.456789

print(f"Price: {price:.2f}")
print(f"Price: {price:.3f}")
```

Output:

```text
Price: 123.46
Price: 123.457
```

The value is rounded for display; the original variable is not changed.

### 12.6 Formatting percentages

```python
percentage = 0.8567

print(f"Percentage: {percentage:.2%}")
```

Output:

```text
Percentage: 85.67%
```

### 12.7 Formatting numbers with commas

```python
salary = 1500000

print(f"Salary: {salary:,}")
```

Output:

```text
Salary: 1,500,000
```

For Indian-style comma grouping:

```python
salary = 1500000

print(f"Salary: {salary:,}")  # International-style grouping
```

Python's standard `,` format uses three-digit grouping. For Indian-style grouping such as `15,00,000`, you can use an appropriate locale-aware formatting solution or a custom formatting function.

### 12.8 Alignment and width

F-strings support alignment and minimum field width.

| Format | Meaning |
| :--- | :--- |
| `<` | Left alignment |
| `>` | Right alignment |
| `^` | Center alignment |

Example:

```python
name = "Python"

print(f"{name:<15}")
print(f"{name:>15}")
print(f"{name:^15}")
```

Output:

```text
Python         
         Python
    Python     
```

### 12.9 Formatting dates

F-strings can format date and time objects.

```python
from datetime import datetime

today = datetime.now()

print(f"Date: {today:%d-%m-%Y}")
print(f"Time: {today:%H:%M:%S}")
```

The actual output depends on the current date and time.

### 12.10 Debugging with f-strings

Python also supports the `=` syntax in f-strings.

```python
x = 10
y = 20

print(f"{x=}")
print(f"{y=}")
print(f"{x + y=}")
```

Output:

```text
x=10
y=20
x + y=30
```

This is useful when debugging code because it displays both the expression and its value.

### Important points about f-strings

* Available from Python 3.6 onward.
* Use `f` or `F` before the string.
* Expressions are evaluated when the f-string is created.
* Curly braces are used for interpolation.
* To display literal curly braces, double them.

Example:

```python
name = "Rahul"

print(f"{{Hello, {name}}}")
```

Output:

```text
{Hello, Rahul}
```
